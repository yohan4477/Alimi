# SeoulBeauty 디자인 리뷰 — 2026-10-19

> 이 문서는 **휴리스틱 UX 리뷰이자 디자인 제안**이다. 실제 디자이너 인터뷰·사용자 테스트·제품 성과 측정 결과가 아니다. 관리자 웹의 **디자인 리뷰** 탭과 동일한 평가 틀을 사용한다.

## 핵심 판단

**개인화된 커뮤니티 발견은 유지하되, 사용자가 피부 정보를 입력하기 전에 서비스 가치를 이해하도록 한다.** 기존 Community, Search, My Activity 하단 탭과 게시글 / 실시간 채팅, 상품 카드 첨부, 브랜드 탐색, 저장·재방문은 유지한다. 소비자 가격 추적은 되살리지 않는다.

- UX 리서처 관점: 처음부터 입력을 요구하면 가치 체험을 지연시킨다. 한 화면 피부 선택과 **먼저 둘러보기** 경로를 제안한다.
- 인터랙션 관점: 추천 결과만이 아니라 추천 이유, 최근 유효 대화, 입장 후 첫 읽기·답변을 연결한다.
- UI 관점: 기존 홈 구조를 전면 교체하지 않고 참여 대화 아래에 추천 모듈을 삽입하며 모바일 배치·언어별 길이를 검수한다.
- 콘텐츠·신뢰 관점: 피부 정보는 선택·비공개 기본값으로 설계한다. 피부 타입이 같다고 효능이 동일하다는 인상을 주지 않는다. 사용자 글은 원문으로 표시한다.

## 검증 기준

**북극성 지표(가설):** 첫 유의미 참여율 = 신규 이용자 중 관찰 기간 내 첫 질문, 댓글 또는 실제 채팅 메시지를 남긴 이용자 수 / 동일 기간 신규 이용자 수. 단순 방 입장·상품 클릭은 포함하지 않는다. 관찰 기간, 이벤트 정의, 중복·테스트 유입 제거 기준은 실험 시작 전 확정한다.

**A/B 후보:** A는 첫 화면에서 선택형 피부 관심사 입력을 제안하고, B는 커뮤니티를 먼저 보여준 뒤 같은 관심사 선택 카드를 제시한다. 첫 대화 열람률과 첫 유의미 참여율로 비교하며 언어·디바이스별 분리한다. 어느 쪽이 낫다고 사전 확정하지 않는다.

**가드레일:** 유용한 답변 비율, 무응답 질문, 답변까지 걸리는 시간, 신고·차단, 고객 문의, 언어·빈 상태 오류, 입력 부담, 추천방의 콘텐츠 부족.

**배포 전 디자인 수용 조건:** 한국어/영어 2개 언어에서 모든 주요 화면 검수; 320/390/1024px 너비에서 넘침 없음; 비로그인 둘러보기 가능; 추천 데이터 없는 경우 인기 주제 대체; 피부값 미선택 및 변경·초기화 가능; 제품 효능·인구 특성 자동 추정 금지; 게시글·상품 링크·이전 화면 복귀 유지.

현재 UX 제안과 화면 미리보기는 **관리자 보드에만 반영**되었다. 사용자 앱 코드, 실운영 관리자 계정, 배포, A/B 실험, 실제 이벤트 수신은 별도 검증 전이다.
