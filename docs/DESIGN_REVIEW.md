# SeoulBeauty 디자인 리뷰 — 2026-10-19

> 이 문서는 **휴리스틱 UX 리뷰이자 디자인 제안**이다. 실제 디자이너 인터뷰·사용자 테스트·제품 성과 측정 결과가 아니다. 관리자 웹의 **디자인 리뷰** 탭과 동일한 평가 틀을 사용한다.

## 핵심 판단

**개인화된 커뮤니티 발견을 유지하되, 스킨케어·메이크업을 둘 다 선택할 수 있게 하고 관심사 입력 전에 대화의 가치를 먼저 보여준다.** 기존 Community, Search, My Activity 하단 탭과 게시글 / 실시간 채팅, 상품 카드 첨부, 브랜드 탐색, 저장·재방문은 유지한다. 소비자 가격 추적은 되살리지 않는다.

- UX 리서처 관점: 처음부터 입력을 요구하면 가치 체험을 지연시킨다. 한 화면에서 스킨케어·메이크업 **복수 선택**과 각 분야 고민 **다중 선택**, **먼저 둘러보기·전체 방 탐색·자유 생성** 경로를 제안한다.
- 인터랙션 관점: 추천 결과만이 아니라 추천 이유, 실제 최근 대화, 입장 후 첫 읽기·답변을 연결한다. **추천은 누구나 만든 방을 찾는 도구이지 생성 허가나 고정된 방 연결이 아니다.**
- UI 관점: 기존 홈 구조를 전면 교체하지 않고 참여 대화 아래에 추천 모듈을 삽입하며 모바일 배치·언어별 길이를 검수한다.
- 콘텐츠·신뢰 관점: 피부 정보는 선택·비공개 기본값으로 설계한다. 피부 타입이 같다고 효능이 동일하다는 인상을 주지 않는다. 사용자 글은 원문으로 표시한다.

## 픽셀 한복 가이드 UX 결정 (온보딩 P0 · 의상 꾸미기 P1)

- **디자인 목표**: 포켓몬식 작은 픽셀 캐릭터가 환영→고민 선택→발견으로 짧게 안내하되, 사람 사이의 대화가 중심. 캐릭터는 **80~110px** 높이의 작은 2D 하늘색 한복 소녀 한 명; 풀스크린 그림·반복 애니메이션·몬스터·레벨/미션 없음.
- **3단계**: (1) Skincare/Makeup **동시 복수 선택** (2) 선택 분야별 고민 **복수 선택** (3) 추천 채팅방 **실제 활동/추천 이유** 확인 후 입장 또는 전체 탐색·자유 방 만들기. 피부 타입/톤 입력·캐릭터 선택·로그인 강제하지 않음.
- **캐릭터는 안내자**, 사용자 아바타는 별도의 사후 개인화. 기보유 한복/무대 의상 영감 10종은 검증 후 My Activity의 선택적 아바타 꾸미기 후보이며, 인물·피부/인구 속성 추정에 사용하지 않음.
- **검증 가드레일**: 건너뛰기·초대 딥링크·기존 방 복귀, 영어/한국어 대사 완전 분리, 접근성(화면읽기/큰 글씨/모션 감소), 실제 첫 질문/답변·D7. 캐릭터 애니메이션이 대화를 가리거나 화면 체류만 늘리면 채택하지 않음.
- **자산 게시 전** 실제 10종 이미지 파일을 앱에 등록·검수하고 권리/파일명/프리뷰를 확인해야 함. 보유 자산이 있다고 해서 배포됐다는 뜻은 아님.

## 검증 기준

**북극성 지표(가설):** 첫 유의미 참여율 = 신규 이용자 중 관찰 기간 내 첫 질문, 댓글 또는 실제 채팅 메시지를 남긴 이용자 수 / 동일 기간 신규 이용자 수. 단순 방 입장·상품 클릭은 포함하지 않는다. 관찰 기간, 이벤트 정의, 중복·테스트 유입 제거 기준은 실험 시작 전 확정한다.

**A/B 후보(별도 축):** A는 첫 화면에서 스킨케어·메이크업/고민 복수 선택을 제안하고, B는 자유 방 탐색·생성을 먼저 보여준 뒤 같은 선택 카드를 제시한다. **캐릭터 자체의 효과는 동일한 선택/추천 UI에서 가이드 있음 vs 없음으로 별도 비교한다.** 첫 대화 열람률과 첫 유의미 참여율로 비교하며 언어·디바이스별 분리한다. 어느 쪽이 낫다고 사전 확정하지 않는다.

**가드레일:** 유용한 답변 비율, 자유 생성 방의 첫 타인 참여·무응답, 답변까지 걸리는 시간, 신고·스팸·차단, 고객 문의, 언어·빈 상태 오류, 입력 부담. 방 이용시간은 화면 가시/포커스 유효 시간의 중위값과 p75로 제안하며 전략 측에서 목표를 협의한다.

**배포 전 디자인 수용 조건:** 한국어/영어 2개 언어에서 모든 주요 화면 검수; 320/390/1024px 너비에서 넘침 없음; 비로그인 둘러보기·자유 방 생성 가능; 추천 데이터 없어도 전체 탐색·방 생성 제공; 스킨/메이크업 두 분야 및 다중 고민 선택·해제·변경 가능; 피부 정보 선택·비공개; 제품 효능·인구 특성 자동 추정 금지; 게시글·상품 링크·이전 화면 복귀 유지.

현재 UX 제안과 화면 미리보기는 **관리자 보드에만 반영**되었다. 사용자 앱 코드, 실운영 관리자 계정, 배포, A/B 실험, 실제 이벤트 수신은 별도 검증 전이다.
