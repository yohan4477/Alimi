# 명화 게임 — 상위 시나리오와 그림의 연결

2026-10-23 KST. 최신 사용자 확정: 캐릭터는 재미와 시각적 맥락을 제공하고, 분석의 중심은 상위 상황이다. 그림에서 보이는 특징→세부 상황→가상 상태→추천 방향→제품군→제품·옵션→복수 이유를 연결한다.

## 현재 6개 그림의 분류

| 상위 상황 | 세부 상황 ID | 그림 | 그림에서 보이는 연결점 | 게임에서 부여한 가상 설정 |
|---|---|---|---|---|
| 중요한 약속 전 | first_date | 모나리자 | 차분한 표정·은은한 미소 | 소개팅 전 입술 건조·표현 고민 |
| 중요한 약속 전 | evening_party | 마담 X | 검은 드레스·격식 있는 분위기 | 파티 직전 제한된 시간·번들거림·입술 건조 |
| 외출 중 정돈할 때 | after_class | 진주 소녀 | 귀걸이·가까이 보이는 얼굴 | 수업 뒤 건조한 볼·번들거리는 코·베이스 수정 |
| 외출 중 정돈할 때 | after_sea_breeze | 비너스 | 바다·긴 머리카락 | 해변 바람 뒤 모발 정돈 |
| 오래 외출할 때 | sunny_picnic | 양산을 쓴 여인 | 햇빛·양산·야외 | 긴 피크닉·볼 건조·선케어 |
| 집에서 관리할 때 | after_a_day_out | 오필리아 | 물·꽃·자연 배경 | 원작 이야기와 구분한 외출 후 세안·보습 설정 |

오필리아의 원작 장면을 실제 즐거운 물놀이나 촬영으로 설명하지 않는다. 밝은 사진 촬영 이야기로 확대할 때는 재해석 이미지와 새 콘텐츠 버전을 준비한다. 명화 이미지로 실제 피부·모발 상태나 인물의 진짜 생활을 판정하지 않는다.

## 남자 두 캐릭터 — 학교생활 정체성 초안

두 그림의 확정 이름이 아직 없으므로 `character-drafts.json`에 이미지 미배정 상태로 보관한다. 실제 서비스 목록이나 집계에 가짜 캐릭터로 노출하지 않는다.

| 슬롯 | 정체성 | 상위 상황 | 첫 문구 | 추천 방향·실제 후보 |
|---|---|---|---|---|
| school_photo_friend | 사진에 진심인 꾸미기파. 친구들과 방과 후 사진·카페, 친구 립도 골라주는 성격 | 중요한 약속 전 | 오늘 네 컷 찍는데. / 얼굴에 어디부터 포인트 줄까? | 얇은 베이스: 정샘물·헤라 쿠션 / 파우더: 라네즈·힌스 / 립: 롬앤·퓌·헤라 |
| school_last_minute_friend | 등교 준비가 늘 막판인 실속파. 늦잠·체육·학원, 간편함 우선 | 시간이 부족할 때 | 등교까지 5분. / 뭐 하나만 챙겨서 뛸까? | 헤어: 미쟝센·라도르 / 입술 케어: 에뛰드·라네즈 / 빠른 베이스: 정샘물·헤라 |

얼굴과 그림의 특징은 유지하되 학교생활·말투·가방·파우치로 재해석한다. 웃음의 중심은 진지한 명화 분위기와 현실적인 일상의 대비다. 성별을 비하하거나 여고생 성격·말투를 하나로 일반화하지 않는다. 최종 그림을 연결할 때 시각적 단서와 상황의 적합성을 다시 확인한다.

## 구현과 집계

- `scenario-taxonomy.js`는 버전 `scenario-v1`, 다섯 상위 상황, 여섯 현재 그림의 기본 소속·세부 ID·그림 연결 근거를 보관한다. 한 세부 상황은 기본 상위 상황 하나에만 속해 중복 집계를 피한다.
- 화면에서 '이 명화의 상황'과 '같은 상위 상황'을 전환한다. 상위 집계에서도 응답별 명화·세부 상황·추천 방향을 유지한다. 동일한 로컬 방향 ID를 다른 그림끼리 같은 뜻으로 합치지 않는다.
- 서버는 허용된 현재 그림과 scope만 받는다. 현재 게임 버전·테스트 여부를 유지해 SQL 매개변수로 조회한다. 공개 결과에는 개인 메모·기기 ID·사용자 프로필을 넣지 않는다.
- 상위 상황별 제품군 선택 건수를 제공한다. 후보 제품군이 다른 세부 상황들의 단순 합계를 같은 조건의 선호율·실사용률·효능 순위로 해석하지 않는다. 공정한 제품군 비교 실험은 공통 후보 조건을 별도 설계한다.
- 게임 추천, 본인 실제 사용 응답, 판매처 클릭·구매는 별도 데이터다. 같은 계정/기기에서 여러 세부 상황에 답하면 응답 수가 늘며, 상위 합계를 고유 사람 수로 표시하지 않는다.
- 기존 저장 답을 새 내용으로 변경하거나 피부·생활 속성을 추론해 채우지 않는다. 기존 응답을 현재 분류로 조회한 결과임을 taxonomyVersion으로 식별한다. 콘텐츠를 실제 변경할 때 게임/후보 버전을 별도 관리한다.

## 검증

Node 계약 검사: 모든 현재 그림에 단일 상위 그룹·그림 연결점 존재, 남자 초안 두 개의 미공개 상태·실제 후보 유효성 확인. 격리 D1 검사: 모나리자 개별 집계와 마담 X를 포함한 상위 집계의 수 차이, 세부 상황 보존, 제품군 합계, 잘못된 범위 거부, 테스트/운영 격리, 개인 메모 미노출 확인. 실제 모바일 기기·100명 동시 접속 부하를 통과했다는 의미는 아니다.
