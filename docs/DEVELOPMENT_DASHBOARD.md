## 최신 코드 및 배포 증거 범위

- GitHub main `5cdb7d62ff4267f20153bd87074b84f01070ffca`에 대한 **GitHub Vercel combined status = failure**, target build-rate-limit (2026-10-19 확인). **Vercel 계정 직접 조회는 scope 403이라 추가 검증하지 못함**. 업데이트 후에도 별도 READY 배포가 확인되지 않으면 운영 완료가 아니다.
- PR #109(복수 고민 기획), #108(전략 KPI), #107(대화 시작)은 merged. PR #105(선택형 아바타), #102(공유)는 2026-10-19 확인 당시 open. PR 머지 자체는 운영 검증이 아니다.
- 웹·iOS 캐릭터 로딩 코드 존재. 캐릭터를 통한 **실제 신규 사용자 온보딩**과 **실제 방 추천**, 실제 첫 발화 이벤트 A/B와 D7은 구별한다.
- 소비자 가격 이력·목표가·가격 푸시를 복원하지 않는다. 기존 핵심 탭·자유 방 생성·상품 상세·공유 동선을 유지한다.

## 구현과 동작

- **서버 콘텐츠**: `server/admin-page.html`. HTML/전략 문구·작업 상태는 이 서버 전용 파일에만 둔다.
- **클라이언트 프레젠테이션**: `dist/admin.css`, `dist/admin.js`. P0/P1 및 Web/iOS/Backend 필터는 DOM 표시만 바꾸며 서버/PR/사용자/실측 값을 쓰지 않는다.
- 개발 탭에서 전략·서비스 기획·디자인 리뷰 버튼은 기존 5개 탭으로 이동한다. `/admin#sb-dev` 딥링크로 초기 탭 선택 가능하다. 기존 `/admin#sb-plan` 딥링크와 탭 키보드 내비게이션을 유지한다.
- 관리자 서버 인증·HttpOnly 세션·CSRF 보호·no-store / CDN 차단은 변경하지 않는다. **민감 데이터와 사용자별 정보는 대시보드에 추가하지 않는다.**
- 관리자 스냅샷과 소비자 실제 동작/실험을 섞지 않는다. 숫자가 없으면 `0`이나 가상 달성률 대신 `미측정`.

## 검증 게이트

1. 정적/Node: 정확히 6개의 tabs+panels, 10개 개발 항목, 소스·우선순위·플랫폼 속성, 코드를 포함한 페이지 인증 보호, 기존 인증 테스트 통과.
2. 브라우저: 6탭 전환, 개발 탭 첫 진입·딥링크, P0/P1·플랫폼 조합 필터, 탭 간 점프, 320/390/1024px 넘침 없는지 확인.
3. 실제 배포: Vercel READY + 해당 commit SHA + 관리자 로그인/권한 차단 + 소비자 흐름 확인. 브라우저·서버 CI 또는 운영 검증을 실제 수행한 뒤만 완료 표시.
4. iPhone 및 계측: 실기기 플로우, 온보딩↔추천↔대화↔상품, 이벤트 수신·D7, 제휴 승인 원장 대조. 별도 체크.
