# 한국 이용자 초기 실험 · 올리브영 제휴 적용 계획

결정: 2026-10-20 KST, 제품 책임자 John Choi가 대화에서 “저걸로 일단 진행하자” 승인. 한국 이용자 대상 채팅 실험의 첫 제휴 후보를 올리브영 쇼핑 큐레이터로 선정한다. 글로벌 장기 방향과 구분하며 한국 초기 실험을 우선한다.

## 현재 상태

- 제휴처 선정·준비 진행 승인. 가입, 매체 사용 확인, 링크 발급, 정산 승인, 운영 연결은 미완료.
- 기존 웹 `dist/live.js`의 buyUrl과 iOS `ios/Alimi/Models.swift`의 Purchase.buyURL은 상품별 affiliate_url/affiliateUrl을 지원한다. clickref 추가는 Awin 호스트에만 적용한다. 올리브영 링크를 Awin으로 변환하지 않는다.
- 화면 개편이나 신규 가격 추적 기능은 필요하지 않다. 현재 해외 판매처 상품 링크를 한국 구매 링크로 일괄 교체하지 않는다.
- 실제 큐레이터 링크가 없으므로 가짜 제휴 링크·상품·수익을 등록하지 않는다. 일반 올리브영 주소를 제휴 승인 링크처럼 표시하지 않는다.

## 공식 확인 조건

- 외부 공유 링크의 추천 상품 직접 구매 기본 수수료 7%, 다른 상품 간접 구매 3%.
- 클릭 후 24시간 이내 주문, 주문 전 마지막 링크가 해당 링크여야 인정. 본인 구매는 제외.
- 공식 발급 페이지에서 생성한 링크만 사용하며 임의 수정하지 않는다.
- 관련 상품 콘텐츠와 경제적 이해관계 표시 필요. 공식 안내 문구: “이 포스팅은 올리브영 쇼핑 큐레이터 활동의 일환으로, 구매 시 일정 금액의 수수료를 제공받습니다.”
- 첫 정산 누적 5천 원, 이후 1만 원부터. 매월 21일~말일 신청, 채널·콘텐츠 캡처와 정산 승인 필요. 상세 조건은 적용 시 최신 가이드와 약관 우선.
- 자체 앱·실시간 채팅·이용자 콘텐츠에 운영자 링크를 연결하는 방식, API 및 상세 실적 제공 범위는 공개 가이드만으로 확정하지 못했다.

## 실행 순서

1. 계정 소유자가 올리브영 앱에서 쇼핑 큐레이터 활동 시작 및 약관 확인.
2. 자체 웹·iPhone 앱의 상품 상세 구매 버튼과 채팅 상품 카드에 운영자 명의 링크를 게시하는 구조의 매체 인정 여부 확인. 임의 외부 문의 발송은 하지 않음.
3. 한국 초기 대화에서 다룰 10~20개 상품의 링크 발급. 브랜드·상품명·용량·색상·단품/기획세트 일치 확인. 다른 옵션으로 자동 대체 금지.
4. 검토용 매핑에 내부 상품 식별자, 올리브영 상품 식별자, 정확한 옵션, 원본 큐레이터 URL, 확인일, 매체 확인 상태 기록. URL은 원문 보존.
5. 승인 범위 내에서 기존 상품 상세의 구매처로 연결하고 상품 상세 상단에 제휴 안내 표시. 상품 이미지·설명·가격 제공 권한은 제휴 링크와 별도 확인.
6. iPhone에서 웹/판매처 앱 이동 및 복귀 확인. 링크 발급과 실적 집계는 별도로 검증. 실적 검증에 본인 구매를 사용하지 않음.

- 관련 대화·상품 상세의 경제적 이해관계 표시 위치 및 승인용 캡처 방식은 적절한가?

- 외부 브라우저에서 올리브영 앱으로 이동하는 경우 구매 기여가 유지되는가?

## 측정과 완료 기준

서울뷰티 자체 계측: 상품 상세 조회, 올리브영 구매 버튼 클릭, 상품 식별자, 진입 위치. 개인 대화 내용·개인 식별자를 외부 URL에 넣지 않는다. 발급 URL에 임의 UTM/clickref를 추가하지 않는다.

올리브영 실적: 제공되는 범위의 주문·취소·확정 수익을 별도로 기록. 클릭을 실거래로 계산하거나 특정 사용자의 구매로 추정하지 않는다. 공개 가이드의 상세 실적 외부 공개 제한을 따르며 관리자 접근 범위를 검토한다.

완료 조건: 계정 활동 시작 → 매체 사용 방식 확인 → 정확한 상품 링크 확보 → 제휴 표시·구매 연결 → 실제 iPhone 왕복 → 제공된 실적과 정산 검증. 현재는 첫 단계 이전의 적용 준비이며 수익화 출시가 아니다.
