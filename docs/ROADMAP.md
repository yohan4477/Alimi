# SeoulBeauty 실행 로드맵

## 2026-10-20 사용자 확정 — 글로벌 목표·한미 병행 검증

- 미국 진출은 확정 목표이며 한국 성과를 미국 진출의 선행 조건으로 두지 않는다. 한국은 접근성 높은 초기 운영·제품 개선 시장, 미국은 실제 고객 수요를 동시에 검증하는 시장이다.
- 서비스는 Seoul Beauty 하나. `/kr`와 `/us`에서 지역별 홈·대화·판매처를 구분하고 계정·브랜드·공통 기능은 공유한다. 지역과 화면 언어는 별도 선택·저장한다. 언어 변경은 대화·판매처 국가를 바꾸지 않는다.
- 국가별 모집 링크는 목적 대화/제품과 서비스 지역을 유지한다. 국가 전환은 새 지역 홈으로 이동하며 다른 국가 방에 자동 입장하지 않는다. 작성자가 쓴 대화는 원문 유지.
- 관심·고민 복수 선택 → 선택형 연령/피부 정보 → 제품별 대화찾기. 방 자동 입장 없이 제품·관련 방을 선택한다. 주제별 탐색·자유 방 생성도 유지한다.
- 제품별 목록: 제품명·관련 방 수·진행 중인 대화 주제 미리보기. 결과 없으면 해당 제품을 제목에 담아 방 만들기로 연결한다.
- 첫 질문 실험: 한국은 효과·사용감·피부 적합, 미국은 피부 적합·효과·예산·사용 편의성을 가설로 비교한다. 조사 자료는 채팅 수요나 18~24세 전용 결과를 입증하지 않는다.
- 한미별 유입 → 주제별/제품별 진입 → 첫 발화 → 답변 → 상품 → 판매처 → 승인 수수료와 D7을 따로 집계한다. 이벤트별 고유 기기는 순차 퍼널이 아니다. 주문/정산·D7은 여전히 미검증.
- 중간 로딩 캐릭터/인물 이미지와 게임형 온보딩은 현재 구현 지시에서 제외한다. 기존 3탭·디자인 유지.
- 운영 DB 프로젝트 `mqsnshnlfwsgabrsmqsz` SQL 접근 권한 없음 확인. 지역 마이그레이션은 미적용이며, 한국 방·실판매처 데이터 연결은 운영 완료가 아니다. 미분류 기존 방은 기존 미국 파일럿으로 처리하며 한국 피드로 재분류하지 않는다. 한국 데이터가 없으면 준비 중/빈 상태를 표시한다.

## 핵심·후속·제외

- 핵심: 스킨케어·메이크업 관심/고민 복수 선택, 기존 공개 방 추천과 **누구나 자유로운 방 생성**, 대화·경험 공유, 정확한 상품 연결, 현재 가격·판매처, 브랜드 탐색, 저장·재방문.
- 검증 후 결정: 사진, 선택 피부 정보, 번역 확대, 인플루언서 콘텐츠, 개인화·리워드.
- 보류: 시술·병원 연결, 공급자 서비스·리포트·API, 다국가 총액 비교와 추가 상품군.
- 제외: 소비자 가격 추적·이력·목표가·가격 알림. 기존 데이터·서버 수집의 삭제/중단을 의미하지 않는다.
