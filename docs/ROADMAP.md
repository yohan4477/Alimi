## 핵심·후속·제외

- 핵심: 스킨케어·메이크업 관심/고민 복수 선택, 기존 공개 방 추천과 **누구나 자유로운 방 생성**, 대화·경험 공유, 정확한 상품 연결, 현재 가격·판매처, 브랜드 탐색, 저장·재방문.
- 검증 후 결정: 사진, 선택 피부 정보, 번역 확대, 인플루언서 콘텐츠, 개인화·리워드.
- 보류: 시술·병원 연결, 공급자 서비스·리포트·API, 다국가 총액 비교와 추가 상품군.
- 제외: 소비자 가격 추적·이력·목표가·가격 알림. 기존 데이터·서버 수집의 삭제/중단을 의미하지 않는다.

## 실행 관리

구현·CI·실기기·운영 배포·TestFlight 업로드·Apple 처리·사용자 실험은 각각 기록한다. PR 병합이나 문서 정리로 나머지 상태를 완료로 올리지 않는다. [현황](PRODUCT_STATUS.md)은 시점별 증거, 상세 Issue는 작업별 상태의 원장이다. 담당은 제품 책임자 John Choi이며 실험 운영·검증 실행 담당은 착수 시 지정한다.
