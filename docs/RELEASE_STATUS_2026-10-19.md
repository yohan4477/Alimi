# Seoul Beauty — 기획·디자인·개발 상태

기준: 2026-10-19 22:47 KST. 수동 확인 기록. 사용자 기기의 설치 상태와 실측 KPI는 확인하지 않았다.

## 기획

- 고객 여정: 신규 유입·고민 기반 추천 / 탐색·대화·상품 발견 / 재방문·저장·공유.
- 하단은 커뮤니티 / 탐색 / 내 활동 3개. 참여방은 내 활동, 알림은 상단 종, 프로필·설정은 내 활동. 온보딩·대화방에서는 탭을 숨긴다.
- 현재 추천: 스킨케어·메이크업 복수 선택 + 고민 키워드 + 실제 방 활동. 고정 방 강제 배정 없음.
- 후속 제안: 1/3 관심·고민 → 2/3 선택형 연령대·피부 정보 → 3/3 추천. 필드·저장·공개 범위와 추천 활용 확정 후 구현. 정확한 생일·실명·성별은 현재 제안 범위에 없음. 피부 타입·톤·언더톤은 선택형, 잘 모르겠어요·건너뛰기 제공.
- 현재 첫 입력 2/3 표시는 스플래시를 1단계로 센 구현이며 수정 전이다. 위 3단계 확장안은 21.1에 포함되지 않았다.

## 디자인

- 사용자 제공 Journey 1·2·3의 이미지·카드·말풍선·색상·타이포를 유지한다.
- 상품 카드·이미지 영역 테두리·그림자 제거, 흰 배경. 상품 사진·브랜드 로고 유지.
- 사용자 아바타 임시 숨김 및 여백 보정. 가이드·로딩 캐릭터와 구분한다.
- 팔로우 아이콘·문구 한 줄, 안전 영역, 배너 전체 표시, 태그 줄바꿈·상품 옵션·터치 영역 보정.
- 온보딩 다음·이전의 좌우 슬라이드 제거. 제자리 교체.
- 픽셀 단위 일치·한영 작은 화면·실기기 최종 검수는 미완료.
