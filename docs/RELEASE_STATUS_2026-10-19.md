기준: 2026-10-19 23:21 KST. 후속 배포·웹/iOS 자동검사 완료. 수동 확인 기록. 사용자 기기의 설치 상태와 실측 KPI는 확인하지 않았다.

## 기획

- 고객 여정: 신규 유입·고민 기반 추천 / 탐색·대화·상품 발견 / 재방문·저장·공유.
- 하단은 커뮤니티 / 탐색 / 내 활동 3개. 참여방은 내 활동, 알림은 상단 종, 프로필·설정은 내 활동. 온보딩·대화방에서는 탭을 숨긴다.
- 현재 추천: 스킨케어·메이크업 복수 선택 + 고민 키워드 + 실제 방 활동. 고정 방 강제 배정 없음.
- 22.1 반영: 1/3 관심·고민 → 2/3 선택형 연령대·피부 정보 → 3/3 추천. 연령대·피부 타입은 기기 내 저장, 연령대는 추천에 사용하지 않음. 정확한 생일·실명·성별은 현재 제안 범위에 없음. 피부 타입은 선택형. 톤·언더톤은 이번 범위 제외. 미입력으로 다음 진행 가능.
- 22.1에서 첫 입력 1/3 → 선택형 정보 2/3 → 추천방 3/3 구현. 스플래시는 단계 제외. 21.1에는 미포함.

- 팔로우 아이콘·문구 한 줄, 안전 영역, 배너 전체 표시, 태그 줄바꿈·상품 옵션·터치 영역 보정.

## 22.1 반영 — 심플한 고객여정

- 기존 디자인과 하단 3탭 유지. 커뮤니티의 생성 버튼 하나를 항상 노출. 추천방 화면에서도 생성 가능.
- 온보딩 3단계 유지: 관심·고민 1/3 → 선택형 연령대·피부 타입 2/3 → 추천방 3/3. 스플래시는 단계 제외.
- 선택형 정보는 기기 내 저장. 연령대는 추천에 사용하지 않음. 건성·지성은 관련 고민을 보조하며 직접 선택한 고민 우선.
- 상품 브랜드 이름을 눌러 브랜드를 탐색하고 원래 대화에 상품 첨부. 저장은 북마크, 대화 좋아요는 하트.
- 공유 웹 링크는 웹에서도 열리며 ‘앱에서 열기’로 seoulbeauty URL scheme 처리. Universal Links 자동 전환은 포함하지 않음.
- 알림 집계의 첫 8개 방 제한 제거. 서버 메시지 조회 범위와 기기별 읽음 상태의 한계는 유지.
