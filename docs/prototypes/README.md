# SeoulBeauty 사용자 여정 HTML 프로토타입

2026-10-22 사용자 여정 덱(v07)의 여정별 세부 화면을 독립 HTML로 옮긴 것이다. 화면 배치·문구 확인용 시안이며 운영 데이터가 아니다.
숫자·후기·가격·인물 사진은 덱 예시를 옮긴 것이고 앱(`dist/`)에는 실제 데이터만 쓴다.

| 파일 | 여정 | 앱 적용 |
|---|---|---|
| [journey-2.html](journey-2.html) | 2 대화 탐색 (2-1 주제별 ~ 2-5 관련 대화 추천) | 탐색 탭, 검색 필터, 대화방 소개 카드, 관련 대화 |
| [journey-3.html](journey-3.html) | 3 채팅방 참여 (3-1 ~ 3-5) | 공지 제목, 전체/최신순/인기순, 내 메시지 '나' 표시, 경험 시트 제품 첨부. 3-3 닉네임 설정은 API 없음(서버가 익명 태그로 생성) |
| [journey-4.html](journey-4.html) | 4 제품 사용 경험 공유 (4-1 ~ 4-5) | 3단계 경험 시트, 대화 속 경험 태그. 사진 첨부는 채팅 메시지에 사진 필드가 없어 제외 |
| [journey-5.html](journey-5.html) | 5 대화 속 제품 발견 → 구매처 이동 (5-1 ~ 5-5) | 상품 시트 요약/대화/판매처/관련 제품 탭, 판매처 선택. 별점·평점 막대·함께 언급된 제품은 검증 데이터 없음 |
| [journey-6.html](journey-6.html) | 6 재방문 · 저장 · 알림 · 공유 (6-1 ~ 6-5) | 대화방 북마크(기기 저장), 내 활동 저장한 대화 탭, 상품 공유 시트, 홈 새 알림 배너·최근 본 대화. 카카오톡·인스타그램 공유는 SDK 미연동 |

공통 규칙: 하단 탭은 커뮤니티 / 탐색 / 내 활동 3개로 고정(덱의 탭바 불일치는 이 규칙으로 통일). 대화방·시트·상품 상세·알림·공유 화면에는 하단 탭이 없다.
`assets/`의 이미지는 덱에서 잘라낸 저해상도 예시이며 권리 확인 전이므로 앱에 넣지 않는다.

덱의 채팅 프로필 사진(아바타)은 기존 제품 결정(아바타 제거)에 따라 앱에 넣지 않았다.
