# SeoulBeauty 사용자 여정 HTML 프로토타입

2026-10-22 사용자 여정 덱(v07)의 여정별 세부 화면을 독립 HTML로 옮긴 것이다. 화면 배치·문구 확인용 시안이며 운영 데이터가 아니다.
숫자·후기·가격·인물 사진은 덱 예시를 옮긴 것이고 앱(`dist/`)에는 실제 데이터만 쓴다.

`assets/`의 이미지는 덱에서 잘라낸 저해상도 예시이며 권리 확인 전이므로 앱에 넣지 않는다.
