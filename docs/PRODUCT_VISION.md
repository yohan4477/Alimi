# SeoulBeauty 제품 비전

## 현재 방향 — 2026-10-19

한국에 관심 있는 사람들이 주제별 글·댓글과 실시간 채팅에서 제품과 경험을 나누고, 정확한 상품·옵션과 제휴 판매처를 확인해 구매하도록 돕는다. K뷰티부터 시작하며 가격 이력·알림은 구매 판단의 보조 기능이다. 상품별 후기는 커뮤니티 후기 글을 재사용한다. 피부 특성·사진·구매처는 선택 입력이며, 장기적으로 동의와 표본 품질이 검증된 집계 트렌드 리포트·API를 검토한다.

현재 설계·구현 범위·미완료 게이트: [커뮤니티 커머스](COMMUNITY_COMMERCE.md). 아래는 10월 15일 당시 비전 기록이며 현재 데이터·출시 상태의 원장으로 사용하지 않는다.


기준: 2026-10-15 KST. [운영 현황](PRODUCT_STATUS.md) · [로드맵](ROADMAP.md) · [의사결정](DECISIONS.md)

## 해결할 문제

한국 상품을 찾은 소비자가 동일 상품의 가격 이력과 배송비 포함 가격을 확인하고, 원하는 가격이 됐을 때 다시 구매를 판단하도록 돕는다. 시작점은 iPhone용 K-뷰티 가격 추적 MVP다. 현재 데이터는 가상이며 실제 가격·푸시 서비스로 출시되지 않았다.

## 소비자와 공급자

| 대상 | 제공하려는 가치 | 검증할 사업 가설 |
|---|---|---|
| 소비자 | 상품 검색, 가격 이력, 판매처 비교, 관심 상품, 목표가 알림 | 구매 판단과 재방문에 도움이 되는가 |
| 공급자 | 구매 희망가격·경쟁가격·재고/재입고 수요·국가별 수요 분석, 할인 제안, 데이터 API | 실제 업무에 활용하고 반복 지불할 의사가 있는가 |
| 공통 기반 | 상품 동일성, 가격 출처/시각, 동의·계정 격리, 측정 가능한 제휴 | 신뢰를 유지하면서 운영비를 감당할 수 있는가 |

## 확장 방향

iPhone UI 검증 → 실제 가격 → DB·인증 → 푸시 → 사용자 실험 → 제휴 → 글로벌 비교 순서다. 한국/KRW에서 시작해 국가별 배송·세금·환율·배송 가능 여부를 검증한 뒤 확장한다. 글로벌과 공급자 서비스는 구현 약속이 아닌 검토 대상이다.

SNS는 상품 발견 유입 채널이다. 자체 피드·팔로워·추천 알고리즘 경쟁은 하지 않는다. 기존 [Issue #1](https://github.com/yohan4477/Alimi/issues/1)의 권리 확인, 수동 큐레이션, 제품 식별, 실사용/광고 구분 방침을 보존한다.

## 판단 원칙

- 최소 기능별 검증을 먼저 하고, 통과 근거와 사용자 승인 후 다음 개발로 진행한다.
- 기술 작동, 사용성, 시장성, 수익성, 출시를 별개로 기록한다.
- 가상 가격·화면 상태를 실제 수집·푸시·매출로 표현하지 않는다.
- 공급자 인터뷰와 희망가격 등록은 실제 구매나 매출의 증거가 아니다.
- 별도 관리 웹앱은 만들지 않는다. Issues가 기능 원장이고 문서는 전략과 현황을 연결한다.
