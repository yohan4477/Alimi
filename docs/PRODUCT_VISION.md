# SeoulBeauty 제품 비전

기준: 2026-10-19 KST. 현재 사용자 지시가 이전 가격 추적 MVP 방향을 대체한다.

## 현재 미션

해외 이용자가 한국 뷰티에 관해 사람들과 이야기하고, 자신의 피부·취향·상황에 맞는 선택을 하도록 돕는다.
대화와 커뮤니티를 중심으로 상품을 발견하고 경험을 나눈다. 현재 가격·구매처·관심 저장은 선택을 지원한다.

## 현재 제품 범위

- 브랜드·카테고리·검색으로 상품을 탐색하고 커뮤니티에서 질문·경험을 나눈다.
- 현재 상품가와 출처를 표시하고 실제 판매처로 연결한다. 배송비·세금 등 미확인 조건은 숨겨진 확정 총액처럼 표현하지 않는다.
- 관심 저장은 다시 찾기 위한 기기 내 상품 스냅샷이다. 저장 시 가격 추적을 새로 시작하지 않는다. 저장 당시 가격은 최신 조건을 보장하지 않으며 판매처에서 확인하도록 표시한다.
- 가격 이력·변동률·목표가·가격 알림을 소비자 화면에서 제공하지 않는다. 가격 추적 서비스로 소개하지 않는다.
- 기존 수집 데이터와 과거 개발 기록은 보존한다. 이번 화면 전환은 운영 데이터 삭제나 모든 서버 수집 작업 중단을 뜻하지 않는다.

## 판단 원칙

- 핵심 가설은 사람들이 질문하고 유용한 답변·후속 대화를 얻어 선택에 도움받는가이다.
- 현재 가격·상품 정보와 실제 제휴 구매·확정 매출을 구분한다.
- 사용자 결정, 구현, CI 검증, 실제 기기 확인, TestFlight 배포를 따로 기록한다.
- [기획박스 #26](https://github.com/yohan4477/Alimi/issues/26)은 현재 미션과 후속 검증의 진입점이다.
- SNS 이미지·브랜드 자산은 출처와 사용 권한을 별도로 확인한다. 커뮤니티 수요·사진 효용·운영 방식은 검증 결과로 판단한다.
