# 판매처 비교 UI 재작업

2026-10-15 사용자 피드백: 가격 흐름 아래 비교 UI를 한국 쇼핑 앱 수준으로 수정.

참고: 네이버 배송비 포함 총액 비교 기준(https://ads.naver.com/notice/16273), 폴센트 가격 추이 및 알림 흐름(https://fallcent.com/). 공개 검색으로 노출된 앱 화면도 참고했으며 로그인 앱 전체를 감사한 것은 아님.

변경: 기존 표 제거, 최저가 카드 강조, 판매처별 배송 조건, 최저가 대비 차액, 가격 구성 펼치기, 목표가 입력 영역 간소화. iOS에도 동일 카드 구조 적용.

검증: 390px 모바일 웹 렌더링 캡처, 가로 넘침 없음, 가격 구성 펼치기 확인. 기존 기능 테스트 6개 통과. iOS 변경은 소스 반영이며 빌드/실기기 검증은 미완료.

가격·판매처는 계속 가상이며 실제 판매처 이동 버튼이나 공식 인증 표시는 만들지 않음.
