# 모바일 발견 → 목표가 저장 흐름 — 2026-10-16 KST

사용자 승인: 우선순위1 진행. 관련 ALM-F1/F2/F4/F5 (#3/#4/#6/#7). 기존 2열 상품 카드·베이지 히어로·가격 차트·하단 버튼을 유지한다.

- 목표가가 있거나 하트로 저장한 상품은 관심 목록에 표시하고 목표 금액을 표시한다. 하트 해제는 목표가를 삭제하지 않는다.
- 발견/관심 탭 전환 때 검색·카테고리를 초기화하여 숨은 저장 상품 문제를 해소한다.
- 상세에서 저장·수정·삭제 후 목록과 개수를 갱신하고, 목록 복귀 시 스크롤과 상품 버튼 초점을 복원한다.
- 저장 실패 문구가 성공 토스트로 덮이지 않도록 수정한다. USD/KRW 저장 키는 유지한다.
- 푸시 미연결 상태에서 알림을 약속하지 않고 목표가 저장으로 표시한다.
- 좁은 화면 토스트 줄바꿈, 44px 관심 버튼, 16px 검색 입력, safe-area 여백을 추가한다.
