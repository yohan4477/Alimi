# 가격 이력 입력 파이프라인 검증 — 2026-10-15

## 범위

PR #29의 기존 웹 UI와 수동 관측 1건을 유지하며, 검토된 관측 JSON → 검증 → 파일 원장 → 브라우저 데이터 → 기존 가격 그래프를 연결했다. 자동 수집기, API/제휴 피드, 서버 DB, 푸시 연결은 포함하지 않는다. 공급원 데이터 사용 승인을 의미하지 않는다.

## 실행

저장소 루트에서 Node.js로 실행한다.

```sh
node scripts/price-pipeline.mjs reviewed-observations.json
npm test
```

입력은 JSON 배열이다. 정확한 형식은 `data/price-observations.json`의 기존 관측을 참고한다. 현재 허용 범위는 COSRX 100ml 1개, Stylevana US 지정 URL, USD, 수동 관측이다. 배송비·세금·재고는 미확인으로 유지한다. 날짜는 UTC 기준이며 정확한 관측 시각은 확보되지 않았다.

기존 원장을 입력하면 중복을 추가하지 않고 브라우저 모듈을 재생성한다.

```sh
node scripts/price-pipeline.mjs data/price-observations.json
```

## 저장과 실패 처리

- `data/price-observations.json`이 원장이고 `dist/observed-data.js`는 재생성 가능한 산출물이다.
- 잘못된 시장·통화·용량·출처·가격·날짜와 같은 날짜의 충돌 가격을 거부한다. 동일 관측 재입력은 무시한다.
- 전체 입력 검증 후 파일별 임시 파일과 rename으로 교체한다. 두 파일 전체의 트랜잭션은 아니다. 단일 작성자로 운영하고, 중단 후 원장을 입력해 산출물을 다시 생성한다.
- CLI 실패는 `data/price-import-errors.jsonl`에 기록된다.
- 같은 날 여러 가격은 정확한 시각을 지원하기 전까지 허용하지 않는다.

## 화면

실제 관측은 2026-10-15의 $17.50 한 건이다. PR #29에서 이관했으며 새로운 관측으로 세지 않는다. 가격은 상품 가격으로 배송비·세금 포함 총액이 아니다. 공개 페이지 캐시 가능성은 원장의 evidence에 남겼다.

기간 내 관측이 2개 날짜 이상일 때만 기존 그래프와 관측 표본의 최고·평균·최저를 표시한다. 1건이면 이력 수집 중과 통계 미제공 상태를 유지한다. 관측 사이 변동은 알 수 없다는 문구를 표시한다. 다른 상품의 데모 데이터는 실제 관측과 구분한다.

## 검증 결과

- 새 파이프라인 테스트 6/6 통과. 전체 저장소 테스트 실행 결과를 의미하지 않는다.
- 무효 입력의 원장/산출물 불변, 중복 멱등성, 같은 날짜 충돌, 날짜 정렬과 최신값을 검증했다.
- JavaScript 문법 검사 통과.
- Chromium 390×844에서 실제 1건의 대기 상태, 메모리에만 주입한 2건의 그래프/평균, 7일 선택, 기간 밖 관측 제외를 확인했다. 가로 넘침과 런타임 오류 없음.
- 합성 테스트 관측은 원장에 저장하지 않았다.
