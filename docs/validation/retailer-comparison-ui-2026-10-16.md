# 판매처 비교 화면 연결 — 2026-10-16 KST

사용자 요청: 우선순위1 후 다음 진행. 관련 #5, #8. PR #33의 모바일 흐름을 기반으로 PR #31의 비교 로직을 브라우저와 CLI가 함께 쓰는 순수 모듈로 이동했다. PR #31의 문서/상태 변경을 병합한 것은 아니다.

## 동작

기존 COSRX 상세 화면의 판매처 행을 재사용 가능한 렌더러로 연결한다. 현재 관측에는 배송지, 정확한 수집 시각, 피드 갱신 시각, 검토된 제형·옵션, 배송비·세금·관세가 없으므로 이를 만들어 넣지 않는다. 배송지 없는 현 화면은 총액 비교 대기로 유지하며 판매처별 제외 이유를 표시한다. 상품가 및 비제휴 상품 페이지 링크는 유지한다.

정규화된 배송지 요청과 검토된 오퍼가 제공되면 compareOffers 결과를 사용한다. 동일 옵션·배송지·재고·시간·비용 요건을 통과한 서로 다른 판매처 2곳 이상만 비교 범위 최저가를 받을 수 있다. 단일 판매처는 최저가 배지를 받지 못한다. 누락 비용은 0으로 처리하지 않는다. 잘못된 입력은 비교를 중단하고 안내한다. 렌더링 문자열 이스케이프 및 HTTPS 링크 검증을 적용했다.

실제 피드/서버/배송지 입력 수집/자동 갱신/푸시/제휴 추적은 이번 범위에 없다. 합성 오퍼는 테스트 파일에서만 사용한다. 원화 데모는 그대로 데모다.

## 검증

Node v24.19.0 Linux, node --test tests/*.test.js: 29/29 통과. 기존 12개 + 비교 로직 12개 + 화면 데이터·HTML 5개. 화면 검사: 실제 수동 관측의 비순위 처리, 합성 두 판매처 총액/구성, 단일 판매처 및 미확인 비용, 오래된 가격·옵션 불일치, 잘못된 요청·HTML 이스케이프·위험 URL 제외.

이는 HTML 생성과 데이터 로직 검증이며 브라우저 터치·레이아웃 검증이 아니다. 앞선 Chromium 설치 실패로 모바일 브라우저/실기기 검증 미완료. 배포나 실제 피드 연동 완료를 주장하지 않는다.
