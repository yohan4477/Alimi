# 게임 → 실제 서울뷰티 초안 연결 1단계

2026-10-23 KST. 흐름: Reflection에서 본인이 작성한 이야기 → 지역 선택·명시적 이동 → 같은 탭 초안 수신 → 실제 지역 대화방 선택 → 기존 글쓰기에서 편집·게시 확인 → 기존 createPost RPC → 성공 뒤 브라우저 초안 삭제.

## 구현 범위

- 게임 추천 답·개인 게임 메모·추정 피부 정보는 전달하지 않는다. Reflection이 만든 본인 이야기 텍스트만 사용한다.
- sessionStorage에 최대 2,000자 본문·120자 제목·생성 시각·지역·언어·무작위 ID를 보관한다. URL에는 ID만 넣는다. 24시간이 지나면 읽기를 거부하고 다음 접근 시 정리한다. 동기화·계정 연결·서버 토큰은 아니다.
- 언어와 지역을 독립적으로 전달한다. 목적 화면은 온라인 모드이며 기존 오프라인 예시 방을 실제 게시 대상으로 사용하지 않는다.
- 대상 홈의 비공개 초안 안내, 복사·삭제·대화방 선택을 제공한다. 실제 목록 실패 재시도, 빈 목록은 새 방 만들기다. 새 방 생성이 실패하면 기존 초안을 지우지 않는다.
- 기존 글쓰기에서 제목·본문을 편집하고 본인이 게시한다. 입력 중 수정을 보관한다. 요청 진행 중 중복 클릭 방지, 실패 시 초안 유지, 성공 뒤 삭제다. 서버 멱등 키는 추가하지 않았으므로 네트워크 응답 유실 후 재시도의 중복 가능성까지 해결한 것은 아니다.
- 기존 community_open 이벤트에 source=beauty_play와 handoff_id만 추가한다. 본문은 분석에 넣지 않는다. 운영 이벤트 수신·순차 퍼널 검증 완료를 뜻하지 않는다.

## 검사 증거

- Node 전체 190/190 통과. 신규 4개 계약 검사: 불투명 URL·필드 허용 목록, 기기/ID/지역/만료 경계, 비정상·과대·미래 시각·저장 차단, 편집 복구·정확한 초안 삭제.
- Vite 게임 빌드 성공. chat.js와 beauty-handoff.js 문법 검사 및 git diff --check 통과.
- 관리형 HTTP 미리보기에서 crypto.randomUUID 부재 확인. 새 초안 helper는 getRandomValues 기반 UUID v4 fallback을 제공한다. 기존 커뮤니티의 WebCrypto 사용은 HTTPS 운영에서 확인해야 한다. QA 임시 페이지는 배포 목록에서 제거한다.
- 운영 브라우저의 초안 도착·방 선택·편집은 배포 후 별도 기록한다. 공개 테스트 글·후기·실구매를 임의 생성하지 않는다.
