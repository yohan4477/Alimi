## 1. 전략 원칙과 사용자 선택권

- 최초 집중층: 미국 18~24세 중 **K-뷰티에 관심이 많고 피부·메이크업 고민이 있는 사용자**. 특정 연령이나 피부 상태를 직접 추정해서 개인화하지 않는다.
- 초기 화면에서는 **Skincare + Makeup을 독립 다중 선택**할 수 있고, 각 분야 고민 태그도 다중 선택한다. 피부 타입·톤 입력은 선택 사항, 건너뛰기 지원.
- **방 생성은 모든 사용자에게 열려 있다.** 온보딩 추천 목록에서만 방을 선택하게 만들지 않는다. 사용자 스스로 자유로운 주제의 방을 만들고, 전체 방 탐색·검색·공유 링크로도 입장한다.
- **추천은 새로운 방을 자동 생성하지 않는다.** 이미 만들어진 공개 방을 고민/분야/주제/실제 활동과 매칭하는 발견 기능. 새 방도 전체 탐색에 노출하며 초기 참여자가 생길 기회를 남긴다. 운영상 제한·신고·스팸 대책은 별개.
- 커뮤니티를 경유하지 않고도 검색→상품 상세→제휴 링크로 바로 이동할 수 있어야 한다. 제휴 관계는 고지한다. 최종 사업 목표는 **취소·반품·귀속 조건 반영 후 승인된 제휴 순수수료 매출**, DAU·체류·클릭은 선행/진단 지표다.
- 다음 모든 목표치는 **전략팀과 협의해 정할 미확정 값**이다. KPI를 표시하기 위해 임의 달성률이나 실제 방문자 수를 생성하지 않는다.

## 2. 실제 고객 동선(서로 연결되는 4개 경로)

| 경로 | 진입 → 핵심 이동 | 분기/종료 | 주된 관찰 |
|---|---|---|---|
| A. 고민 해결 | 유입 → 선택형 관심사·고민 선택/건너뛰기 → 추천방/전체 탐색·검색 → 방 열람 → 질문/답변 → 제품 카드·상세 → 제휴 링크 | 추천방 없음 → 전체 방·직접 방 생성 / 구매 없이 대화 지속 | 단계별 방문자·이동률, 방 체류, 답변, 제품 및 구매 클릭 |
| B. 구매 의도 | 검색·브랜드·공유 딥링크 → 상품 상세 → 관련 대화·후기 또는 판매처 링크 → 확인된 제휴 주문 | 상품→대화→상품 복귀 / 상세에서 바로 판매처 이동 | 검색→상세·상세→대화·상세→판매처·귀속 전환 |
| C. 자유 방 생성 | Community / 추천 결과 / 공유 진입 → **방 만들기** → 제목·설명·태그(선택) → 생성된 방 → 공유/초대 → 첫 타인 참여 → 첫 답변 | 방 미생성·신고·오류·생성 후 무응답 | 생성 시작→완료율, 최초 외부 참여까지 시간, 방 생존/사용 |
| D. 재방문·공유 | 참여 중 방·답변 알림·친구 초대 링크 → 이전 대화 복귀 → 후속 발화/상품 확인 → 다른 사람 공유 | 방문만 하고 대화하지 않음 | D1/D7/D30 코호트, 반복 참여, 공유→실방문→첫 메시지 |

**추천과 방 생성은 별도 기능:** 추천 방 진입이 막혔거나 같은 고민 방이 없더라도 방 생성이 가능하다. **고정된 카탈로그 몇 개만 추천하는 것처럼 설계하지 않는다.** 새로 생긴 방의 주제·참여도·시간에 따라 후보가 계속 바뀔 수 있다.

## 3. 화면별 퍼널 KPI — 분모·이용시간

| 화면/이동 | 핵심 이벤트 초안 | 비율·시간·재방문 정의 제안 | 주의 |
|---|---|---|---|
| 랜딩·홈 | `landing_view`, `community_open`, `search_open` | 신규/재방문 순방문자, 채널별 세션, 홈→첫 콘텐츠 열람률 | 중복 기기·봇·운영자 유입 분리 |
| 관심 선택 | `onboarding_view`, `interest_toggle`, `concern_toggle`, `onboarding_skip`, `onboarding_complete` | 노출자 중 선택/완료/건너뛰기, 스킨만/메이크업만/**둘 다**/미선택 각 집단 이탈률 | 피부 특성 자체를 제휴 `clickref`에 담지 않음 |
| 추천·전체 탐색 | `room_recommendations_view`, `room_browse_view`, `room_search`, `room_open` | **노출→방 열람률**(추천·전체·검색·초대별 별도), 추천 결과 없음 비율 | 실제 생성 방 후보, 같은 방 중복 노출 분모 정리 |
| 방 열람·대화 | `room_view_start`, `room_visible_heartbeat`, `chat_send`, `post_create`, `comment_create` | **방 이용시간** = 포커스/가시 상태의 누적 유효 체류 초, 방문자당 주간 활성 시간의 중위값·p75, 방 진입→첫 발화, 유용한 답변율 | 숨겨진 탭·백그라운드 정지, 봇 제외; 체류가 길다고 좋은 대화로 판단하지 않음 |
| 방 자유 생성 | `room_create_open`, `room_created`, `room_create_failed`, `room_first_other_participant` | 생성 완료율=생성자/생성 시작자, 생성 후 외부 1인 이상 참여 비율, 첫 답변까지 시간, 생성 뒤 D7 유효 방 비율 | 자유 생성 유지, 스팸·악용 가드레일 병행 |
| 제품 연결 | `product_card_impression`, `product_card_click`, `product_view`, `return_to_room` | 대화의 카드 노출→상품 상세, 제품 상세→대화 복귀, 제품 정확한 옵션 선택률 | 카드가 로드되었다고 실제 보였다고 간주하지 않음 |
| 제휴 링크 | `affiliate_link_impression`, `merchant_click` | 제품 상세 방문자→판매처 링크 클릭률; 링크 노출→클릭률 | 클릭은 구매가 아니며 판매처 이동 오류 별도 |
| 승인 구매 | 제휴사 주문/취소/승인 정산 원장(외부) | 귀속 주문/제휴 클릭, 승인 순수수료/1,000명, 월 확정 순수수료 | Awin/Stylevana 등 공식 리포트와 대조; 주문 귀속 실패/정산 시차 표시 |
| 재방문·공유 | `room_revisit`, `share_open`, `share_link_landing` | 신규 참여자 D1/D7/D30, 초대→실제 방문·첫 참여 전환, 질문자/답변자 반복 이용 | 완료되지 않은 코호트를 포함하지 않음 |

**퍼널 계산 규칙(전략·데이터 협의 후 확정):** 단계 전환율은 같은 출발 코호트의 고유 이용자 기준으로 산정하고, 전체 기간 노출 수 대비 전체 기간 클릭 수를 임의로 나눠 전환처럼 쓰지 않는다. 사용자의 경로가 반복/교차하므로 이벤트 건수와 고유 사용자수를 별도로 표시한다. `room_view_start` 이후 heartbeat는 페이지가 실제 가시·포커스인 동안에만 집계하고 연결 끊김·미수신/유휴 시간을 무한 연장하지 않는다. 이용시간은 총합만 말고 **활성 이용자당 중위값, p75**, 방별 분포를 보고한다. 개인정보 원문·피부 고민 텍스트는 제휴 `clickref`에 넣지 않는다.

## 4. 전략 목표에서 서비스 KPI로 내려오는 구조

| 책임 | 결정·검토할 사항 | 이번 확정/제안 |
|---|---|---|
| **전략** | 최종 KPI, 선행 드라이버 우선순위, 실험의 투자·중단 조건 | 확정: **승인된 순제휴 수수료 매출**. 목표치·검증 게이트는 전략 협의 전 |
| **서비스 기획** | 어느 화면에서 어떤 행동을 하게 할지, 방 추천/생성/탐색 병렬 흐름, 누락·빈 상태·이용 시간 | 제안: 네 가지 유입·전환 경로와 화면별 KPI |
| **데이터/개발** | 이벤트 실제 수신·중복 제거·세션/기기 기준·권한·제휴 귀속 원장 연결 | 미완료: 계획 이벤트 존재 ≠ 실제 계측 완료 |
| **운영·신뢰** | 신고·스팸·무응답 방·의료 효능 주장·제휴 고지 | 제안: 방 생성은 자유, 악용 대응과 추천 품질은 별도 조치 |

**전략팀 협의 안건(아직 의결되지 않음):**
1. 핵심 선행 지표를 ‘첫 유의미 상호 대화 참여’와 ‘승인 수수료/1,000 방문자’ 중 어떤 기간/비중으로 볼지, 두 지표의 가드레일은 무엇인지.
2. 관심 그룹(스킨만/메이크업만/둘 다/미선택)과 유입 경로(추천/검색/생성/공유)별 실험 표본·분모, 적정 관찰 기간, 목표·중단 기준.
3. 방 체류시간에 의미 있는 방문만 포함하기 위한 가시성/비활성 기준, 무응답·스팸/신고 허용 범위.
4. 제휴사 승인·반품 시차 및 `clickref` 귀속 신뢰도를 어디까지 검증할지.

협의 결과가 실제로 확인되기 전에는 가설/기획 KPI로만 표시한다. KPI 현황은 **미측정**, 화면 미리보기는 **관리자 전용 기획 시안**으로 표시한다.
