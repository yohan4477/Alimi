# Seoul Beauty UI 디자인 명세 (시안)

- 상태: UI 방향 시안, 구현 전
- 작성일: 2026-10-19
- 범위: 기존 커뮤니티·검색·내 활동 구조에 흰색·파란색 시각 디자인과 화면 연결 규칙을 적용
- 브랜드명: Seoul Beauty는 작업 중인 서비스명 표기. 저장소/앱 식별자는 별도 결정 전까지 변경하지 않음.

## 디자인 방향

기존 화면의 정보 구조와 하단 탭을 유지하면서 초록 계열 UI를 흰색·코발트 블루 중심으로 교체한다. 브랜드 소개, 대화, 상품 정보는 서로 연결하되 별개의 화면 역할을 유지한다.

이 문서는 대화에서 만든 시각 시안에서 추출한 설계 기준이다. 실제 앱의 픽셀 치수, 정확한 색상값, 폰트 파일을 측정하거나 확정한 디자인 시스템은 아니다.

## 디자인 토큰 초안

| 토큰 | 시안 기준 | 구현 메모 |
|---|---|---|
| 화면 배경 | 흰색 또는 아주 옅은 쿨 그레이 | 넓고 밝은 화면 |
| 카드 배경 | 흰색 | 얇은 경계선 또는 미세한 그림자 |
| 주요 강조색 | 코발트 블루 | 선택 탭, 주요 CTA, 링크, 선택 칩 |
| 기본 글자색 | 짙은 차콜 | 제목과 본문 |
| 보조 글자색 | 중간 회색 | 설명, 메타 정보, 비활성 요소 |
| 테두리·구분선 | 밝은 회색 | 화면 구획을 과하게 강조하지 않음 |
| 한글 서체 | 고딕 산세리프 | 제목은 굵게, 본문은 보통 굵기 |
| 영문 브랜드 워드마크 | 브랜드 원래 표기 | 로고 자산을 임의로 재작성하지 않음 |
| 카드 모양 | 둥근 모서리 | 홈 목록, 상품 카드, 선택 시트에 일관 적용 |
| 여백 | 넉넉한 내부·화면 여백 | 모바일에서 카드 간 구분과 읽기 흐름 확보 |

정확한 값과 폰트는 실제 앱에서 사용하는 플랫폼별 서체·기본 간격을 확인한 뒤 지정한다. 시안만으로 특정 폰트(Pretendard 등)가 실제 적용됐다고 간주하지 않는다.

## 내비게이션

기존 하단 탭 3개를 유지한다.

| 탭 | 역할 |
|---|---|
| 커뮤니티 | 대화 탐색, 참여한 대화 이어보기, 화제 상품, 질문 시작 |
| 탐색 | 브랜드·상품 탐색, 인기 브랜드와 브랜드 이야기 |
| 내 활동 | 참여 대화, 저장한 항목, 피부 정보와 앱 설정을 모을 자리 |

- 현재 탭은 파란색 아이콘과 라벨로 표시하고, 비선택 탭은 회색으로 표시한다.
- 새 탭(Explore, Saved, My)을 추가하지 않는다.
- 대화방에서는 메시지 작성 공간을 우선해 하단 탭을 숨긴다.
- 상품 상세에서 ‘대화로 돌아가기’를 선택하면 해당 상품을 열었던 대화방으로 복귀한다.

## 화면별 구성

### 커뮤니티 홈

1. 상단: Seoul Beauty 워드마크, 검색, 알림
2. 참여 중인 대화로 돌아가는 바로가기
3. 활발한 대화 목록: 대화 제목, 최근 대화 일부, 참여·활동 정보
4. 대화에 많이 나온 상품 카드 목록
5. 질문 작성 CTA
6. 하단 탭: 커뮤니티 선택 상태

대화 목록에서 프로필 사진이나 실명에 의존하지 않는다. 익명 표시와 사용 맥락을 제공하되, 피부 속성은 사용자가 직접 입력한 경우에만 표시한다.

### 대화방

- 대화 제목과 짧은 주제 설명
- 익명 닉네임, 선택형 피부·사용 맥락 태그
- 메시지 말풍선
- 메시지 안에 삽입되는 상품 카드: 상품 이미지, 브랜드, 상품명, 옵션 요약, 상품 상세 진입
- 작성 영역: 메시지 입력, 상품 추가, 전송
- 대화방 안에서는 하단 탭을 숨김

상품을 첨부할 때 사용자는 상품 검색 후 카드를 선택하고, 대화 전송 전에 첨부 미리보기를 확인할 수 있다.

### 상품 상세

- 상단 뒤로가기. 채팅에서 진입했다면 라벨은 ‘대화로 돌아가기’
- 대표 상품 이미지, 브랜드명, 상품명, 용량·색상·호수 등 옵션
- 브랜드명 또는 ‘브랜드 이야기 보기’ 링크
- 출처가 구분된 상품 정보
- 해당 상품이 언급된 관련 대화
- 대화로 공유하는 경우 ‘대화에 상품 첨부’ 동작

가격 추적·가격 이력·목표가·가격 알림을 추가하지 않는다. 현재 가격이나 판매처를 보여주는 기능은 별도 기존 제품 정책과 데이터 확인을 따른다.

### 브랜드 이야기

- 브랜드 이미지와 브랜드명
- 브랜드 소개 영역
- 브랜드의 상품 목록과 상품 상세 진입
- 관련 대화 진입
- 진입 경로가 검색이면 검색 탭 선택 상태

브랜드 소개 문구와 상품 설명은 허용된 출처에 기반해 표시한다. 출처가 확인되지 않은 효능·성분·임상 주장이나 사용자 경험을 공식 정보처럼 쓰지 않는다.

### 검색

- 브랜드·상품 검색 입력창
- 인기 브랜드 목록 또는 브랜드 타일
- 브랜드 이야기 미리보기
- 브랜드별 상품 탐색
- 하단 탭: 검색 선택 상태

브랜드명은 로고 유무와 무관하게 텍스트로 표시한다. 상품/브랜드를 둘러보다 대화에 공유할 수 있어야 한다.

### 대화방 선택 시트

상품 상세에서 ‘대화에 상품 첨부’를 누르면 대화방 선택 시트를 연다.

- 대화방 제목, 최근 활동 메타 정보, 선택 라디오
- 선택한 상품 미리보기
- ‘상품 첨부’ 확인 버튼
- 확인 후 해당 대화방의 작성 영역에 상품 카드 삽입

## 주요 사용자 흐름

### 커뮤니티에서 상품을 발견

`커뮤니티 홈 → 틴트 대화 → 메시지의 상품 카드 → 상품 상세 → 브랜드 이야기 보기 → 브랜드 이야기`

- 커뮤니티 홈의 대화 카드에서 틴트 대화로 들어간다.
- 대화 메시지에 붙은 상품 카드로 상세를 연다.
- 상품 상세의 브랜드 링크를 누르면 해당 브랜드 이야기로 이동한다.
- 브랜드 이야기에서 뒤로가기를 누르면 진입한 상품 상세로 돌아간다.

### 검색에서 대화로 상품 공유

`검색 → 브랜드 발견 → 브랜드 이야기/상품 목록 → 상품 상세 → 대화에 상품 첨부 → 대화방 선택 → 상품 카드 첨부`

- 검색에서 브랜드 또는 상품을 찾는다.
- 상품 상세에서 ‘대화에 상품 첨부’를 누른다.
- 대화방을 선택하고 첨부를 확인한다.
- 선택된 대화방의 입력 영역에 상품 카드가 붙는다. 사용자가 메시지와 함께 전송한다.

## 콘텐츠와 시안 데이터 원칙

- 시안에 등장한 WHIPPED, CLIO, 상품 이미지, 메시지와 문구는 화면 배치 설명용 예시다.
- 이미지와 카피를 실제 브랜드 공식 자료 또는 실제 사용자 리뷰로 표시하지 않는다.
- 공식 정보, 판매처 제공 정보, 사용자 게시물을 UI에서 구분한다.
- 실제 상품 데이터·이미지·가격·판매 가능 여부는 출처와 권한을 확인한 뒤 연결한다.
- 가격 추적, 목표가와 알림은 현재 서비스 방향에 포함하지 않는다.

## 상태와 검증

이 명세는 UI 설계 기록이며 구현 완료나 테스트 통과를 의미하지 않는다. 시안 이미지의 UI 텍스트·상품 정보는 예시이므로 실제 데이터와 구분해야 한다. 화면을 코드에 적용한 뒤 웹/모바일 각각에서 경로 및 뒤로가기 동작을 확인한다.

## 2026-10-19 22:09 KST 결정: 3개 고객 여정과 하단 3탭

사용자가 재첨부한 Journey 1/2/3 시안의 화면 디자인을 기준으로 유지한다. 하단만 **커뮤니티 / 탐색 / 내 활동**으로 통일한다. 이전 5탭 목표는 이 결정으로 대체한다.

| 고객 여정 | 화면과 진입 경로 |
|---|---|
| 신규 유입·고민 해결 | 스플래시 → 관심사·고민 → 추천방 → 대화. 온보딩과 대화방에서는 하단 탭 숨김 |
| 탐색·대화·상품 발견 | 커뮤니티 또는 탐색 → 상품·브랜드 상세 → 대화에 첨부·구매 → 원래 대화 복귀 |
| 재방문·저장·공유 | 내 활동의 저장 상품·참여방 → 상단 종 아이콘의 알림 → 해당 콘텐츠·공유 → 커뮤니티 복귀 |

- 알림 화면과 공유 화면은 보존하고 진입점만 조정한다. 알림은 커뮤니티·내 활동 상단 종, 설정은 내 활동에서 접근한다.
- 로고·이미지·카드·말풍선·색상·타이포는 시안 기준. 안전 영역과 좁은 화면 잘림만 보정한다.
- 예시 가격·별점·참여자 수를 운영 데이터로 복제하지 않는다. 소비자 가격 하락 알림과 미구현 초대 리워드는 제외한다.
- 코드 반영과 운영 배포/실제 기기 시각 검증은 별도 상태다. 본 변경만으로 시안 1:1 재현 완료를 뜻하지 않는다.
