# SeoulBeauty 서비스 기획

기준: 2026-10-19 KST. [전략](STRATEGY.md)을 화면·행동·수용 기준으로 옮긴다. 아래는 목표 경험과 검토 후보이며 전체 구현·출시 완료 명세가 아니다. 개별 구현 상태는 Issue와 PR·검증 증거를 따른다.

## 핵심 사용자 흐름

커뮤니티 진입 → 관심 주제·대화 읽기 → 질문·답변·후속 대화 → 연결 상품 확인 → 저장 또는 판매처 이동 → 대화·상품 재방문.

검색·브랜드 탐색으로 들어온 이용자도 상품에서 관련 대화와 경험을 찾을 수 있게 한다. 웹과 iPhone에서 같은 개념·표현을 사용하되 플랫폼별 배치와 실제 동작은 각각 검증한다.

| 화면·영역 | 이용자의 일 | 목표 경험·기획 | 최소 수용 기준 |
|---|---|---|---|
| 커뮤니티 홈 | 어디서 무엇을 이야기할지 찾기 | 주제·최근 대화·질문 진입. 단순 이미지 피드보다 대화 맥락을 우선 | 빈 화면·로딩·오류·재시도 구분, 주제에서 대화까지 이동 |
| 대화·글 | 묻고 답하고 경험 나누기 | 익명 표시와 간단한 작성. 글·댓글과 실시간 채팅의 역할을 구분 | 작성·답변·재방문 시 문맥 유지, 실패 시 입력 손실 방지 |
| 상품 첨부 | 이야기하는 상품을 바로 보여주기 | 대화 중 검색 → 정확한 상품·옵션 선택 → 사진·이름이 있는 카드 | 첨부·열기·취소, 검색 결과 없음·오류, 상품 오연결 방지 |
| 상품 상세 | 어떤 상품인지 이해하고 경험 확인 | 상품 설명·옵션·관련 대화·후기·현재 가격·판매처 | 작성한 분류 설명과 허용된 공식 설명 구분, 미확인 효능 생성 금지, 판매처 이동 |
| 브랜드·검색 | 원하는 상품 찾기 | 공식 로고·브랜드 필터와 검색. 로고 셀 여백·터치 영역 일관성 | 실제 상품 필터, 선택 상태·로딩·실패·빈 결과, 모바일 겹침 없음 |
| 저장·내 활동 | 관심 상품과 대화 다시 찾기 | 상품 저장과 작성·참여 기록의 역할 구분 | 상품 저장→재방문 유지, 추적 요청 없음, 기기 내 스냅샷의 가격 한계 표시 |
| 참여자 표시 | 경험의 맥락 판단 | 익명 닉네임 중심. 사진형 프로필은 필수로 두지 않는 안을 우선 검토 | 실제 신원 공개를 요구하지 않음. 사용자 구분·대화 연속성은 유지 |

## 검증 후 확정할 기능

- 사진: 발색·사용 경험 설명에 추가 효용이 있는지 확인한다. 기존 사진 관련 구현이 있어도 운영 정책과 실제 검증을 완료한 것으로 보지 않는다.
- 피부 타입·톤·고민: 선택 입력을 검토한다. 인종·피부 특성은 사진이나 행동에서 추정하지 않는다. 비슷한 조건이 같은 효과를 보장하지 않는다.
- 언어: 제품명 SeoulBeauty 표기를 일관되게 유지한다. 기존 영어·한국어 흐름과 번역 범위·원문 확인·상품 고유명을 검토하고 언어별 화면을 검증한다.
- 사진형 프로필·번역 확대·개인화·리워드는 이번 문서 정리로 개발 착수하지 않는다.

## 신뢰·운영과 데이터

현재 가격의 출처와 확인 시각을 구분하고 배송비·세금·재고 미확인은 확정 총액으로 표현하지 않는다. 제휴 링크임을 고지하고 클릭과 주문·정산을 구분한다. 브랜드 로고는 출처 기록과 사용 권한 확인을 별도 항목으로 관리한다.

상품·후기 사진, 삭제·신고·차단·홍보 관리, 개인정보와 위치 메타데이터 처리 등은 실제 공개 범위에 맞춰 검증한다. 개인 후기는 개인 경험으로 표시하고 검증된 구매 후기처럼 오인시키지 않는다. 상세 구현 기록: [COMMUNITY_COMMERCE](COMMUNITY_COMMERCE.md).

공통 이벤트 후보: 주제 진입, 질문 작성, 답변·후속 대화, 상품 첨부·열기, 저장·재방문, 판매처 클릭, 확인된 주문. 수집 여부와 동의·식별 범위는 실제 구현 및 정책과 대조하며 이 문서만으로 수집 완료를 주장하지 않는다.

## 전략과 기능을 연결하는 예

| 전략 가설 | 기획안 | 확인할 결과 |
|---|---|---|
| 비슷한 조건의 경험이 선택에 도움된다 | 선택 피부 정보와 질문 맥락 표시 | 선택에 도움 응답·후속 질문, 입력 부담 |
| 상품을 다시 찾는 수고가 크다 | 대화 중 상품 검색·카드 첨부 | 정확한 상품 도달·첨부 성공, 대화 흐름 유지 |
| 좋은 답변이 재방문 이유가 된다 | 질문·답변과 참여 기록 복귀 | 답변 확인·후속 대화·질문자와 답변자 재방문 |

개별 기능의 상세 상태·담당·차단·테스트는 #26이 연결하는 기존 Issue를 갱신한다. 같은 기능을 새 Issue로 복제하지 않는다.
