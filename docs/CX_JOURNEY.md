## 공통 불변조건
- 상단 커뮤니티 탭 **추천/대화방/발견**, 하단 **커뮤니티/탐색/내 활동** 유지. 알림용 하단 탭, 새로운 후기 피드, 필수 피부 프로필 추가 금지.
- 주제별 방은 주제 아이콘, 제품별 방은 확인된 실제 제품 이미지(없으면 기본 아이콘), 브랜드별 방은 권리가 확인된 로고.
- 미국/한국 지역별 콘텐츠·판매처 분리, 언어 선택은 지역 자동 변경을 의미하지 않음.
- 실제 회원 후기와 운영자 질문, 자기신고와 구매 인증, 조사 사례와 시장 빈도를 구분. 원문·사진·닉네임의 무단 Reddit 재게시 금지.
- 가격 이력·목표가·가격 변동 알림 제외. 현재 가격·검증된 판매처 정보는 구매 지원으로 제한.
- Reddit과의 차별화는 입증된 사실이 아닌 **실제 사용 조건·결과·해결 경험을 대화와 정확한 제품에 연결해 비교하기 쉽게 만든다는 검증 가설**.

## 개발 전 미해결
운영 DB RLS/RPC 확인, 익명 계정 복구/기기 변경, 경험-메시지 트랜잭션, 메시지 딥링크, 신고 및 개인정보 보존 정책, 이벤트 수신·코호트 검증. 이미지 PPT는 기획 시안이지 실제 구현 캡처가 아님.
