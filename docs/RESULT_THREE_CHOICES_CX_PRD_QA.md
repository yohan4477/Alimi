# Seoul Beauty · 명화 종료 화면 세 갈래 UX / CX / PRD / QA
2026-10-24. PR #224. **미배포·QA 미완료**.

## 범위 및 브랜드
- 기존 명화, 상황, 추천 방향, 제품·옵션·선택 이유 및 결과 이미지는 변경하지 않는다.
- Seoul Beauty: “Beauty is personal. Let's talk.” 세 갈래는 같은 브랜드의 놀이이며 외부 사이트 유도가 아니다.
- 게임 완료 뒤 ① 친구는 뭘 골랐을까? ② 너도 이거 갖고 있어? ③ 다른 명화 골라주기를 동등한 선택지로 제시한다.

## CX 시나리오
1. 게임 결과 카드에서 친구 비교 선택 → 기존 공유 영역으로 스크롤 → 실제 고유 링크 생성 → 친구 열람 → 친구가 동일 상황에서 선택 → 완료 후에만 두 결과를 공개한다. 링크 생성 오류/공유 취소/클립보드 실패를 구별한다.
2. 제품 소장 투표 선택 → 아직 출시되지 않았음을 정직하게 알린다. 출시 후에는 게임에서 선택한 product ID·옵션을 연결하며 독립 제품 진입도 허용한다. 첫 질문 후 추가 질문은 선택 사항.
3. 다음 명화 선택 → 현재 코드의 **초대 링크 생성 후 해제** 정책을 유지한다. 이는 이전 CX 제안 중 '공유 강제 없이 자유 진행'과 상충하므로 UX 검증 후 별도 의사결정이 필요하다. 현재 PR은 정책을 임의로 바꾸지 않는다.
