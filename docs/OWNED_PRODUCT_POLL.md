# 너도 갖고 있어? — 현재 개발·출시 기준

2026-10-24. 단일 운영 DB: Alimi → SeoulBeauty (`mqsnshnlfwsgabrsmqsz`). 게임 저장·친구 공유는 이미 이 DB를 사용한다. 관리 도구에서 프로젝트가 안 보이는 것은 접근 권한 문제이며 새 DB/D1 복귀 사유가 아니다.

## 출시 상태

**소장 투표는 비활성.** 코드 반영, DB 적용, 배포, 실제 검증은 별개다. `OWNED_POLL_ENABLED` 및 계정 연결 설정은 이 변경에서 활성화하지 않는다. D1 운영 연결은 제거됐지만 실제 삭제와 과거 데이터 전체 이전 완료를 의미하지 않는다.

## 구현

- 기존 게임 화면/포스터/브랜드·카드 스와이프를 유지. 게임의 결과 CTA는 플래그가 켜진 경우에만 제품 ID·옵션·언어·테스트 맥락을 전달한다.
- `dist/owned-poll/`: 기존 투표 화면의 한국어/영어 분리, 네 가지 첫 답변, 후속 질문, 건너뛰기, 결과, 선택적 비공개 한마디, 제품 이동/검색/브랜드 필터.
- 게임 제품 40개와 별개로 기존 `catalog_items`를 조회하는 전체 카탈로그 탐색 경로. 판매처·시장·SKU를 포함한 ID를 서버에서 실제 활성 제품과 대조한다. 운영 전체 카탈로그 연동 검증은 권한 확보 후 별도다.
- 선택 제품 변경 시 이전 요청은 새 제품 결과를 덮어쓰지 않는다. 저장 중 중복 요청/제품 이동을 막고 이미지 실패 대체 문구를 제공한다.
- 투표는 서명된 익명 브라우저 기준 제품별 최신 1표, 테스트/실사용 분리. 게임 계정과 동일인 통합이나 기기 간 복원까지 구현됐다는 뜻은 아니다.
- 한마디는 비공개이며 결과/관리자 지표에 반환하지 않는다. 가상의 응답/후기는 없다.
- 관리자 게임·투표 탭: 최근 7일 게임 시작/완료/초대/비교, 소장 투표 참여·후속 질문 응답률·다른 제품 탐색률 및 출시 설정. 미연결/접근 거부/미수신/마이그레이션 확인 필요를 구분한다. 기능 설정을 바꾸는 원격 토글은 제공하지 않는다.

## DB 적용 전 확인 순서

1. 실제 운영 프로젝트 ID와 마이그레이션 원장을 조회한다. 현재 관리 도구 연결은 해당 프로젝트 접근이 거부되므로, 이미 적용됐는지 임의로 단정하지 않는다.
2. `20261023090000_owned_product_polls.sql`의 기존 테이블/필드/유일성을 확인한다. 적용 기록이 없는 파일을 무조건 재실행하지 않는다.
3. 신규 `20261024021206_ownership_readiness_metrics.sql`을 검토하고 기존 원장과 대조한 뒤 적용한다. 기존 제품/투표 데이터를 삭제하지 않는 추가 마이그레이션이다. 기존 2컬럼 유일성은 제품/브라우저/테스트 3컬럼 유일성으로 교체한다.
4. 프리플라이트 SQL로 RLS·권한·함수·필드를 확인한다. 기존 서버 전용 키와 투표 서명키 설정을 확인하되 로그/클라이언트에 노출하지 않는다.
5. 별도 승인된 출시 시점에만 플래그를 활성화하고 운영 API/브라우저/모바일 검증한다. DB 적용이나 CI 통과만으로 일반 사용자 공개 완료라고 하지 않는다.

## 검증 구분

- 단위/API 모형: 검색/ID 검증/번역/집계 상태/이벤트 계약.
- PostgreSQL 통합: 수정·중복·테스트 분리·역할 권한·RLS·관리자 집계/이벤트 중복.
- 브라우저 fixture E2E: 375/390/430px, 한/영, 첫 답변 저장·모든 분기·건너뛰기·메모·재방문·제품 이동·빈 검색·이미지 실패·비활성 상태. 실제 운영 DB 및 실물 iPhone 검증과 구별한다.
- 운영 DB 적용, 실제 투표 브라우저 E2E, 실물 기기 및 기기 간 계정 통합: 아직 완료 아님.

다른 제품 탐색률은 같은 페이지 방문(run)에서 제품을 연 방문 대비 두 번째 고유 제품을 연 방문 비율이다. 새로고침은 새 방문이며 기기 간 사람 수가 아니다. 5명 테스트는 정성 관찰용이며 성공을 입증하는 통계 실험이 아니다.
