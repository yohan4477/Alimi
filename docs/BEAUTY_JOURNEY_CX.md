# 뷰티뷰티 → 서울뷰티 전체 CX v1.0

기준일: 2026-10-23 KST. 제품 책임: John Choi. 기획 범위는 유입부터 재방문까지이며 아래 목표 경험이 모두 구현됐다는 뜻은 아니다. [기능·데이터·검증 PRD](BEAUTY_JOURNEY_PRD.md) · [현재 구현 현황](PRODUCT_STATUS.md).

## 1. 경험의 목적

명화 속 인물에게 상황에 맞는 제품을 골라주는 재미로 시작한다. 자신의 선택과 친구의 선택을 비교한 뒤, “그럼 너는 어때?”를 통해 실제 고민과 사용 경험을 말하게 한다. 서울뷰티에서 비슷한 고민을 읽고 답하고, 필요한 제품을 찾고 구매를 판단하게 한다. 구매하지 않아도 유용한 대화와 재방문은 독립적인 가치다.

뷰티뷰티는 게임의 이름, 서울뷰티는 이후 대화·경험·상품 탐색이 이어지는 서비스다. 미국 수요 검증과 한국 운영·개선은 병행하며 한국 성과를 미국 진출 조건으로 두지 않는다. 국가별 대화·판매처와 화면 언어는 분리한다.

## 4. 첫 파일럿 콘텐츠

초기 노출은 모나리자·마담 X 두 상황으로 제한한다. 여섯 인물과 24개 추천 방향이 코드에 있어도 초기 실험 표본을 분산시키지 않는다. 캐릭터별 관심도는 동일한 노출 기회 또는 노출 대비 시작률로 비교한다.

| 콘텐츠 묶음 | 상황 예시 | 선택 데이터의 의미 | 상태 |
|---|---|---|---|
| 모나리자 | 소개팅 전 입술 표현·사용감 고민 | 립 제품·실제 호수·고른 이유 | 초기 파일럿 |

| 야외 하루 | 햇빛 아래 오래 머무는 가상 상황 | 선케어에서 중요하게 보는 조건 | 후속 콘텐츠 |

| 인물 인상 | “이 인물은 어떤 스타일일까?” | 캐릭터에 대한 인상·취향 | 실제 사람·참여자 성격 추론에 사용 금지 |

동일 제품군에서 고르기는 색·제품 선호, 다른 제품군에서 하나 고르기는 상황별 우선순위다. 두 데이터를 한 순위에 섞지 않는다. 명화만 보고 피부 타입을 판정하지 않고 게임의 가상 설정임을 밝힌다.

## 5. 모바일 화면 기준

- 명화 영역은 모바일 뷰포트 높이의 1/2(50svh). 나머지 영역에는 현재 단계 하나와 진행 버튼을 우선 배치한다.
- 선택 완료 항목은 수정 가능한 요약으로 접는다. 제품·옵션 모두 수평 스크롤, 브랜드 기본값 전체, 사진 비율·박스 높이 고정.
- 기본 선택은 사진 4~5개 내외를 탐색하게 하되 한 화면에서 모든 후보를 동시에 강요하지 않는다. 브랜드 필터는 후보가 충분할 때 의미 있게 동작해야 한다.
- 선택 배경은 흰색, 테두리·체크로 구분. 기존 서울뷰티 파랑 #2857d2와 타이포 체계를 따른다.
- 한국어 화면은 한국어, 영어 화면은 영어로 작성한다. 이용자가 쓴 대화는 원문 유지. 지역 전환과 언어 전환은 별개다.
- '훈수', '먼저, 네 훈수는?', '콘텐츠와 출처'를 화면 제목으로 사용하지 않는다. 설명·권리 기록은 운영 데이터에서 관리한다.
- 한 화면 목표는 핵심 선택과 버튼을 함께 볼 수 있다는 뜻이다. 작은 화면·확대 글자에서는 잘라내기보다 스크롤과 접근성을 보장한다.

## 6. 공유 경험

기본 문구는 “모나리자 립 골라줬는데, 너랑 취향 같을까?”처럼 친구의 선택에 대한 호기심이다. 보낸 사람 답과 결과 색상은 카드·첫 화면·이미지에 노출하지 않는다. 같은 질문·같은 제품 후보에서 친구가 새 답을 저장한 후 함께 공개한다.

둘이 다르면 “친구는 색, 너는 촉촉함을 골랐네”처럼 관찰 가능한 차이를 말한다. 한 문제로 취향 일치도 점수를 만들지 않는다. 링크에는 해당 게임에서 공개하기로 한 선택과 이유만 연결한다. 개인 메모·내 실제 고민·프로필·연락처·다른 활동은 공개하지 않는다.

한국 목표: 카카오톡 + 더 보기(기본 공유창) + 링크 복사. 미국 목표: 기본 공유창 + 링크 복사. 공통: 중립 질문 이미지 저장. 현재 카카오 앱 키·도메인 설정은 미완료이며 사용 가능한 버튼으로 가장하지 않는다. 공유창 열림은 발송 성공이 아니다.

## 7. 게임에서 실제 대화로 넘어가는 문구

| 시점 | 한국어 | 영어 |
|---|---|---|
| 내 이야기 | 그럼, 너는 어때? | What about you? |
| 사용 중 | 쓰는 제품 있어 | I have a go-to |
| 탐색 중 | 아직 찾는 중 | Still looking |
| 연결 제안 | 비슷한 고민의 대화를 찾아볼까? | Find conversations about similar needs? |
| 게시 전 | 이 내용으로 글을 올릴까? 수정해도 좋아. | Post this? You can edit it first. |
| 빈 결과 | 아직 대화가 없어. 먼저 물어볼까? | No conversations yet. Want to ask first? |

이는 목표 문구다. 현재는 비공개 답변을 정리·복사하고 서울뷰티 홈으로 이동한다. 아직 관련 대화를 자동 추천하거나 공개 글을 자동 작성하지 않는다. 게임 참여를 피부 설문·회원가입으로 바꾸지 않는다.

## 8. 운영·실험

첫 10~20명은 사용 과정을 관찰하고, 이후 약 100명 누적 파일럿에서 단계별 이탈·공유받은 친구 완료·실제 첫 대화·상품 이동을 확인한다. 100명 누적 이용과 100명 동시 접속은 다른 검증 항목이다. 두 캐릭터를 균등하게 노출하거나 노출 차이를 함께 보고, 작은 표본의 순위를 확정 결론으로 쓰지 않는다.

가설은 ① 상황이 이해되는가 ② 선택할 이유가 있는가 ③ 친구에게 묻고 싶은가 ④ 내 실제 경험을 말하고 싶은가 ⑤ 대화가 제품 판단에 도움이 되는가다. 게임 완료만으로 온보딩 성공이라 부르지 않는다. 정량 지표와 함께 '다른 상황도 할래 / 한 번이면 됐어 / 어떻게 하는지 헷갈렸어'를 받고, 실제 사용자의 표현으로 콘텐츠를 수정한다.

측정은 PRD의 코호트·이벤트 정의를 따른다. 구매나 후기가 없는 초기에도 숫자를 채우지 않으며, 댓글·방·제품 후보가 부족하면 실제 빈 상태로 운영한다.
