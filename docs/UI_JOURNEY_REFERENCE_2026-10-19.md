# Seoul Beauty — 2026-10-19 고객여정 이미지 1:1 UI 기준

사용자가 2026-10-19 대화에서 업로드한 1491×1055 고객여정 시안이 **최종 시각 레퍼런스**다. 원본 이미지는 `docs/reference/journey-2026-10-19/`에 등록했다. 다만 정밀 픽셀 비교·공식 이미지/폰트/배경 자산 교체가 완료됐다고 표시하지 않는다.


## 2026-10-19 22:09 KST 결정: 3개 고객 여정과 하단 3탭

사용자가 재첨부한 Journey 1/2/3 시안의 화면 디자인을 기준으로 유지한다. 하단만 **커뮤니티 / 탐색 / 내 활동**으로 통일한다. 이전 5탭 목표는 이 결정으로 대체한다.

| 고객 여정 | 화면과 진입 경로 |
|---|---|
| 신규 유입·고민 해결 | 스플래시 → 관심사·고민 → 추천방 → 대화. 온보딩과 대화방에서는 하단 탭 숨김 |
| 탐색·대화·상품 발견 | 커뮤니티 또는 탐색 → 상품·브랜드 상세 → 대화에 첨부·구매 → 원래 대화 복귀 |
| 재방문·저장·공유 | 내 활동의 저장 상품·참여방 → 상단 종 아이콘의 알림 → 해당 콘텐츠·공유 → 커뮤니티 복귀 |

- 알림 화면과 공유 화면은 보존하고 진입점만 조정한다. 알림은 커뮤니티·내 활동 상단 종, 설정은 내 활동에서 접근한다.
- 로고·이미지·카드·말풍선·색상·타이포는 시안 기준. 안전 영역과 좁은 화면 잘림만 보정한다.
- 예시 가격·별점·참여자 수를 운영 데이터로 복제하지 않는다. 소비자 가격 하락 알림과 미구현 초대 리워드는 제외한다.
- 코드 반영과 운영 배포/실제 기기 시각 검증은 별도 상태다. 본 변경만으로 시안 1:1 재현 완료를 뜻하지 않는다.

## 화면 명세 (이미지의 순서 유지)

### Journey 1: 신규 유입 / 고민 기반 온보딩
1. 스플래시: Seoul Beauty 워드마크, 하늘색 톤, 메인 비주얼, 시작하기.
2. 관심사/고민: 스킨케어·메이크업 동시 선택 가능, 민감성/건조/여드름/모공·립/베이스/틴트 등 복수 칩; 선택 상태는 솔리드 파란색, 비선택은 파란 테두리 또는 흰색.
3. 고민 추천방: 실제 공개 방만 표시, 썸네일+방 이름+실제 대화 현황+태그+화살표. 검색과 자유 방 생성 경로 포함. 숫자 가짜 데이터 생성 금지.
4. 대화방: 상단 뒤로가기/방 이름/참여, 대화 말풍선/상품 카드/반응, 하단 입력과 사진·상품 첨부.
5. P0 한복 픽셀 가이드는 기존 합의대로 온보딩 내 작은 보조 요소로 유지; 시안 속 인물 사진을 프로필 개인정보로 간주하지 않음.

### Journey 2: 탐색 / 대화 / 상품 발견
1. 커뮤니티 홈: 상단 Seoul Beauty, 추천/대화방/발견/브랜드 서브탭, 지금 뜨는 이야기 3개 이미지 카드, 추천 대화방 리스트, 하단 탐색.
2. 대화 화면: 실제 내용과 연결된 상품 카드. 기존 Posts / Live Chat 구조 보존.
3. 상품 상세: 큰 상품 비주얼·아래 썸네일, 브랜드/상품명/현재 가격/검증된 설명, 저장, 핵심 특징, 파란색 '대화에 첨부' CTA. 미검증 별점/효능 기재 금지.
4. 브랜드: 상단 브랜드 로고·히어로·팔로우(동작 구현 시만), 소개·대표 상품·브랜드 스토리.
5. 이전 채팅으로 복귀: 대화 스크롤·초안 보존, 선택 상품 첨부 후 계속 대화.

### Journey 3: 재방문 / 저장 / 공유
1. 내 활동: 저장 상품, 참여한 대화방 두 탭; 기존 기기 저장과 서버 상태의 차이를 안내.
2. 알림: 전체/대화방/상품/서비스; 알림은 실재 이벤트만 표시, 푸시 권한은 설명 후 요청.
3. 공유: 대화방 공유/상품 공유/친구 초대, 딥링크가 없으면 공개 웹 미리보기로 이동.
4. 복귀 홈: '다시 오신 걸 환영해요' + 참여 대화방의 진짜 새 활동, 기존 기록 복귀.

## 하단 탐색/레이아웃
하단은 **커뮤니티 / 탐색 / 내 활동** 3탭. 원본 시안의 5탭 표시는 22:09 결정으로 대체한다. 참여방은 내 활동, 알림은 상단 종 아이콘, 계정·설정은 내 활동에서 연결한다.
