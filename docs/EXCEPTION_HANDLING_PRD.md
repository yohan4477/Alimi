**주의:** 다음은 위험 분석 및 구현/검증 요구 목록이다. 실제 재현된 결함이나 구현 완료의 목록이 아니다. PR #169는 동일 탭 초안 전달·수정 복구를 일부 검증했으나 서버 게시 멱등성/크로스 기기/실제 정산은 미완료다.

## 공통 불변 조건
1. 오류·인증·재시도 시 입력값과 선택을 보존하고 복구 경로를 제공한다.
2. 비공개 reflection, 개인 메모, 피부 정보 원문을 URL·친구 공유·이벤트·타인 API 응답에 포함하지 않는다.
3. 쓰기는 서버에서 멱등 처리하고, 응답 유실 시 재전송하기 전에 기존 결과를 확인한다.
4. 서버에서 권한·지역·제품/옵션·콘텐츠 버전·외부 목적지 검증을 수행한다.
5. 미수집/미검증/미귀속/실제 0을 명확히 구별한다.

## 구현 계약
- 상태: idle/loading/success/empty/offline/retryable_error/validation_error/unauthorized/forbidden/expired/conflict/pending_confirmation/fatal_error.
- 오류 객체: code,requestId,retryable,safeMessageKey,occurredAt,featureId,operation. 원문·토큰·스택은 제외.
- 쓰기 요청에 안정적인 UUID operation_id를 부여하고 서버 (actor_scope,action,operation_id) 유일성 또는 동등한 트랜잭션 멱등성을 설계한다. 중복 호출에는 기존 결과를 반환한다. 이 계약은 **구현 요구**이다.
- 응답 유실 시 상태를 조회하고, 조회 불가한 구간은 자동 재게시하지 않으며 초안을 유지하고 상태 미확정을 안내한다.
- 기존 same-tab 저장은 sessionStorage/24시간 만료/120자 제목/2000자 본문. 크로스 기기 보장을 암시하지 않는다.
- 장애 계측: 오류 코드, request_id, region, operation, test, recovered, retry_count. 개인 원문 수집 금지.

## 출시 차단 기준
- P0: 작성 내용 복구 불가 소실, 비공개 유출, 서버 중복 게시, 옵션/국가 불일치 구매 링크, 권한 우회, 무한 로딩, 주요 DB 마이그레이션 누락.
- P1(정산 출시 전): 수익 중복/오귀속, 환불 누락, 자가 구매를 실제 인증 주문으로 표기.

## QA 장애 주입 필수 케이스
1. 저장 성공 직후 네트워크 끊김 → 한 건만 기록/복원.
2. 게시 성공 직후 응답 유실 → 동일 게시물 1개, 최신 초안 보존.
3. 인증 취소·토큰 만료·새로고침·저장소 차단 → 안전한 복원 또는 명시적 미지원/복사.
4. 한국/미국 지역과 언어를 독립 변경 → 타국 방/판매처 혼합 없음.
5. 상품·옵션·후보 버전 변경 → 잘못된 SKU 저장 없음.
6. 만료/변조 친구 링크·비교 전 접근 → 비공개 정보 반환 없음.
7. 방 조회 404/429/5xx, DB 컬럼 누락 → 초안 유지, 복구 경로.
8. 중복 클릭 10회 → 의도한 쓰기 1건.
9. 주문 중복 수신·반품·통화 → 순수수료 정확.
10. 실제 iOS Safari/Android Chrome 및 큰 글자/스크린리더/앱 왕복 → CTA 접근 가능.

각 테스트는 코드 커밋, 환경, 예상/실제 결과, CI 로그, 운영 여부를 기록. 테스트 통과를 운영 배포의 증거로 간주하지 않는다.
