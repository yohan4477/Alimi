## 대화 스크롤 핵심 규칙
- 방 최초 방문: 최근 대화와 방 주제를 파악할 수 있도록 최신 영역으로 진입. 과거 이력은 위로 탐색.
- 과거 메시지 읽기 중: 새 메시지 도착 시 강제 맨 아래 이동 금지. '새 메시지 N개'와 최신 이동 제공.
- 내 메시지 전송: 전송 성공 시 본문과 연결; 네트워크 실패 시 원문 유지.
- 답장·알림 딥링크: 정확한 메시지·원문 강조 후 사용자가 다른 대화를 읽도록 허용.
- 투표가 없는 방: 상단 투표 요약 영역 없음. 존재하더라도 채팅 본문보다 시각적 우선순위 낮음.
- 대화량 많음: 오래된 대화 페이징·위치 유지. 요약이 원문을 대체하거나 메시지를 임의 재작성하지 않음.

첫 질문 완료율, 질문→유용한 답변 도달률, 답장 맥락 식별 성공, 과거 대화 찾기 시간, 무응답률, D7 질문자/답변자 재방문, 강제 스크롤 불편 신고. 통계 값은 검증 전 미확정.
