## D-017 / 2026-10-19 — 스킨케어·메이크업 복수 선택, 자유 방 생성과 화면별 퍼널

**방 생성은 누구에게나 열려 있고 주제 제한이 없다.** 고민 선택은 기존 방 추천의 단서이지 방 생성 권한이나 방 접근을 결정하지 않는다. 사용자는 언제든 전체 공개 방 탐색·검색, 방 생성·공유·초대를 사용할 수 있다. 새로 만든 방도 탐색에 표시되며 추천 시스템은 정해진 몇 개의 방으로 강제 연결하거나 자동으로 빈/가짜 대화를 생성하지 않는다. 신고·스팸 등 운영상 남용 방지와 추천 품질은 별도 설계한다.

추가 사용자 요청: 서비스 기획은 신규 유입→온보딩/건너뛰기→추천/검색/생성→방 열람·유효 이용시간→대화→상품→제휴 클릭→귀속 구매와 D1/D7/D30 재방문 **퍼널을 화면별로 정의**한다. 브랜드/상품에서 바로 구매하는 분기와 공유·자유 생성 분기도 독립 추적한다. 최종 KPI **승인·귀속된 순제휴 수수료 매출**은 D-016을 유지하며, 단계별 전환·방 이용시간·유효 답변·구매 KPI의 분모·관찰 기간·목표치·운영 가드레일은 [전략 협의안](FUNNEL_KPI_REVIEW.md)으로 제안한다. 별도의 전략팀 회의나 수치 승인 결과는 아직 없다.

적용 범위: `/admin`의 서비스 기획 탭 및 관리자 전용 인터랙티브 시안, [SERVICE_PLAN](SERVICE_PLAN.md), [FUNNEL_KPI_REVIEW](FUNNEL_KPI_REVIEW.md), [ROADMAP](ROADMAP.md), [PRODUCT_STATUS](PRODUCT_STATUS.md). 기존 Community/Search/My Activity UI, 게시글/실시간 채팅·브랜드·상품 첨부, 현재 가격·판매처, 소비자 가격 추적 제외(D-012) 유지. 관리자 예시 방의 생성·추천은 **데모 데이터만** 다루며 실제 앱의 방 생성 정책·추천 엔진·계측·배포 완료를 뜻하지 않는다.


## D-018 / 2026-10-19 — 한복 픽셀 캐릭터 가이드 온보딩, 의상 선택 분리

사용자의 “포켓몬처럼 처음 방문할 때 캐릭터와 진행” 아이디어를 픽셀 한복 소녀 디자인으로 구체화하고, 가이드 활용 기획 제안에 “ㄱㄱ”로 동의했다. **초기에는 작은 하늘색 한복 2D 픽셀 소녀 1명이 환영→관심 분야(스킨케어·메이크업 동시 가능)→분야별 고민 복수 선택→기존 공개 대화 추천까지 안내한다.** 캐릭터는 서비스 가이드이지 자동 피부 진단사나 유저 실제 정체성 표시가 아니다.

- 기존 D-017의 스킨케어·메이크업 동시 선택, 고민 다중 선택, **건너뛰기·전체 탐색·자유 방 생성**, 피부 타입·톤 후속 선택을 변경하지 않는다.
- 초기 안내 이미지는 80~110px 정도로 작게 둔다. 3D/대형 배경/몬스터/장시간 게임/보상·레벨업은 채택하지 않는다. 모든 문구를 ko/en 별도로 제공한다.
- 사용자가 제작한 **한복 의상 5종과 아이돌 패션 영감 의상 5종**은 초기 온보딩 선택 조건이 아니라 **P1 선택형 사용자 아바타 후보**다. 의상에서 성별·나이·인종·피부 특성을 추론하거나 외부에 자동 표시하지 않는다.
- 캐릭터 유무 A/B를 첫 유의미 참여·D7·이탈/품질로 검증한다. 캐릭터 일러스트 보유≠앱 이미지 등록≠출시·실험 완료.
