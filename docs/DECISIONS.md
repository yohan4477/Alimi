## D-008 / 2026-10-15 — 기존 웹 UI의 가격 이력 기반 구현

D-006의 당시 문서 전용 범위는 이 웹 PoC 구현에 한해 후속 사용자 지시로 대체한다. main 병합·출시 및 외부 데이터 이용 승인을 의미하지 않는다. 실제 관측 1건에서는 추이를 만들지 않고, 2개 날짜 이상일 때 관측 표본 통계를 표시한다. 자동 수집·DB·푸시는 미연결이다. 관련: #8, #4, #7. [검증·롤백 범위](validation/price-history-pipeline-2026-10-15.md). 문제가 있으면 이 PR 변경을 되돌려 PR #29의 수동 관측 화면을 유지한다.
