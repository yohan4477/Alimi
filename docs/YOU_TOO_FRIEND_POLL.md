# 너도 이거 있어? — 친구 공유 MVP

독립 경로: `/you-too/index.html`. 기존 커뮤니티 홈은 변경하지 않는다.

## 사용자 경험
제품 → 소유 응답 → 실제 집계 → 선택적 사용 경험 → 친구에게 물어보기.
공유 전 제품·내 소유 답을 미리 보여준다. 사용 경험 공개는 기본 해제.
수신자는 가입 없이 답한 다음 보낸 친구와 자신의 선택을 비교한다.
다른 수신자의 개별 응답은 공개하지 않는다. 친구는 자기 답으로 다시 공유할 수 있다.
제품 3개로 시작한다. 기존 제품 이미지 URL 매핑을 재사용하며 사진 실패 시 제품명은 유지한다.

## 데이터 정책
- 256비트 브라우저 비밀값으로 익명 참여자를 식별. 서버는 SHA-256 해시만 DB로 전달한다.
- 답변은 참여자/제품당 하나. 수정 시 후속 답과 집계도 교체한다.
- 공유 링크는 공개 가능한 답의 불변 스냅샷을 무작위 UUID로 참조한다. 30일 만료.
- 링크를 전달받은 누구나 스냅샷을 볼 수 있다. 소유자 비밀값·다른 수신자는 노출하지 않는다.
- 인원 10명 미만은 숫자, 이후는 비율도 표시. 분모는 해당 질문 응답자.
- 전체 집계가 없거나 저장에 실패하면 가짜 수치/성공 메시지를 표시하지 않는다.
- 다른 브라우저·기기·저장정보 삭제에 의한 중복은 방지하지 못한다. 공개 모집 전 서버 측 남용 제한을 추가해야 한다.

## 서버 설정 및 공개 전 확인
1. `supabase/migrations/20261022055327_you_too_friend_poll.sql` 적용.
2. Vercel 서버 환경에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 설정. 클라이언트에 넣지 않는다.
3. 이 브랜치를 배포한 뒤 두 기기로 공유/응답/집계 확인.
4. 기존 상품 사진의 이번 공개 용도 사용권, 제품/색상 범위, 개인정보 안내를 확인.

이번 작업은 운영 DB에 적용하거나 운영 사이트에 배포하지 않았다. 서비스 설정이 없으면 503으로 실패한다.

## 측정
`you_too_events`의 product_view, first_answer, followup_answer, share_created, invite_open을 이용한다.
first_answer는 응답 수정으로 증가하지 않는다. 후속 응답은 분기별 재참여가 가능하므로 owner/product를 중복 제거한다.
share_created는 실제 메시지 전송 완료가 아니다. invite_open에는 미리보기/본인 재방문이 포함될 수 있다.
초대 응답은 first_answer.invite로 연결하고 초대 소유자와 같은 owner는 친구 전환에서 제외한다.
두 번째 제품 참여는 first_answer의 owner별 distinct product 수로 계산한다.
재방문은 product_view 시각으로 계산하며 브라우저 단위 지표임을 명시한다.
발신자에게 수신자 답 알림/목록을 제공하지 않는다. 초기 비교 보상은 수신자 화면에서 제공한다.
