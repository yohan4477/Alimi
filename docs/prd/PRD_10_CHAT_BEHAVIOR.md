# PRD 10 — 일반 채팅·긴 대화·답장 상태 명세
상태: 기능 명세 초안 / 기존 코드와 운영 DB 실동작은 미검증.
연결: CX_CHAT_SCENARIOS_V1, CX 03·06, PRD 01·03·04·05·06·09.

## UI 영역
기존 방 헤더(뒤로가기/방 제목/메뉴) → 조건부 투표 한 줄 상태(진행 중일 때만) → 스크롤 가능한 대화 본문 → 메시지 입력창(+ 선택 기능) → 기존 앱의 하단 탭 구조. 메시지/투표/경험이 많아져도 채팅을 기본 가시 영역으로 유지.

## 메시지·답장
- 일반 메시지 전송은 필수 후기/투표/피부 프로필 없이 동작.
- 답장에는 parent_message_id를 둔다. 답장 메시지에서 원본 미리보기와 위치 이동을 제공.
- 원본이 삭제/비공개되면 내용 노출 없이 '삭제되었거나 볼 수 없는 메시지'로 표시.
- 전송 중/성공/실패/재시도, 중복 요청을 구분. 실패 시 초안과 첨부 상태 유지.
- 사용자 소유권·수정·삭제는 서버에서 검증. 닉네임만으로 수정 권한 판단 금지.

## 스크롤·긴 대화
- 초기 최근 메시지 제한 로딩, 상단으로 이동할 때 추가 페이지, 로딩 위치 고정.
- 새 메시지가 왔을 때 사용자가 하단 근처라면 최신 표시. 과거를 읽는 중이라면 스크롤 유지하며 새 메시지 개수와 '최신으로' 제공.
- 알림 링크는 roomId/messageId로 정확한 타깃 조회, 렌더 및 위치 강조.
- 고정 패널은 채팅 높이를 과도하게 차지하지 않도록 한 줄 기본 상태. 메시지 입력 중 소프트 키보드에서 채팅/입력 필드 시야 확보.
- 0건·장기 정체·API 일부 실패·중복·차단 사용자의 메시지 제외 상태를 구분.

## 투표·경험·첨부 상호작용
- 일반 채팅방에는 투표가 0개 가능. 투표가 있어도 필수 참여 아님.
- 투표 카드 원본은 대화 타임라인에 존재. 다중 투표 상태는 작고 접을 수 있는 상단 요약에서 접근.
- 투표 패널을 닫으면 이전 채팅 위치 복구. 진행 중 0개면 요약 숨김.
- 경험 공유/제품/사진 메뉴는 +에서 선택. 일반 채팅의 기본 경로 변경 금지.
- 경험은 사용자가 명시적으로 선택하고 실제 전송할 때만 저장. 게시 후 원본과 메시지 참조.
- 응답자 자율성, 내 직접 답글 알림 조절, 과도한 반복 알림 회피.

## 수용 테스트
1. 투표 0개 방: 상단 투표 요약 없이 채팅과 입력 성공.
2. 투표 1개/여러 개/마감된 투표가 모두 채팅 스크롤을 가리지 않음.
3. 과거 대화 읽기 중 10개 새 메시지 수신: 읽기 위치 유지.
4. 답글 클릭 후 원본 위치 이동·다시 돌아오기.
5. 키보드 표시·화면 회전·폭 320px에서도 입력창과 원문 확인 가능.
6. 실패 후 재시도에서 메시지·경험·투표 중복 생성 방지.
7. 로그아웃/세션 유실 시 권한 없는 기록 복구·열람 금지.
8. 실 사용자 대화/데모/운영자 데이터 혼동 금지.
9. 국가별 언어 전환·접근성(키보드, 스크린리더, 터치 타깃) 검증.
10. UI 승인 후 모바일 실제 앱 테스트, 운영 DB/RLS 검증 후 배포.

## 단계
P0: 기존 자유 채팅·답장·읽기 위치 QA 및 회귀 안전. P1: 긴 대화 탐색·딥링크·투표 상단 상태. P2: 컨텍스트 연계/선택형 경험 심화·타임라인.
