# PRD 01 — 익명 계정·기록 복구

상태: **정책 확정 / 구현 미검증**

## 정책
- 공개 대화 읽기와 첫 메시지 작성에 계정 로그인 강제하지 않음. 익명 닉네임 허용.
- 식별자는 닉네임과 분리된 서버 검증 가능한 내부 주체. 기존 브라우저의 무작위 비밀값/author_tag는 정식 기기간 복구 계정과 다름.
- 계정 연결은 선택적; 저장·재방문·다른 기기 이용 시 필요성이 생길 때 가볍게 안내. 거절 가능.
- 기존 계정에 연결할 때 **본인 확인 후 명시적 데이터 병합 확인**, 자동 병합 금지.
- 계정 연결 전 앱 삭제·브라우저 데이터 삭제·세션 유실 시 기록 복구 보장하지 않음.
- 닉네임 변경·공유 기기·로그아웃·기기 전환·계정 충돌·탈퇴·데이터 삭제를 구분.
- 작성·수정·삭제 소유권은 서버 검증; 닉네임 일치로 권한 부여 금지.

## 수용 기준
1. 비회원이 읽고 익명 닉네임으로 질문/답변할 수 있다.
2. 익명 식별값 변조 시 타인 작성물 수정·삭제가 거부된다.
3. 계정 연결 취소 시 기존 익명 작성 동작이 유지된다.
4. 기존 계정 충돌에서는 병합 전 내역·충돌 처리 안내 및 확인을 받는다.
5. 다른 기기 복구는 연결 계정 인증 및 소유권 재검사 후에만 가능하다.
6. 익명 세션 상실 시 타인 계정·콘텐츠를 회복할 수 없다.

## 구현 전 감사
`dist/chat-api.js`의 기기별 secret/author_tag, auth 연동, Supabase RLS/RPC, 복구·병합 트랜잭션 확인. 운영 프로젝트 접근 권한 미확보.
