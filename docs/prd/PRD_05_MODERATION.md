# PRD 05 — 운영·신뢰·모더레이션

상태: **정책 확정 / 법무·운영 실검증 별도**

## 정책
- 브랜드 관계자·협찬·제품 무상 제공·제휴 관계는 **관계를 명확히 공개하는 조건으로 참여 허용**.
- 직접 사용 자기신고, 검증된 구매, 단순 의견·질문은 서로 다름. 긍정·부정 사용 경험 모두 허용하며 단지 부정적이란 이유로 삭제 금지.
- 신고 콘텐츠는 **위험도별 처리**. 개인정보 유출·직접적 위협 등 긴급 사례는 우선 숨김/검토, 일반 의견 차이는 자동 숨김 금지.
- 신고·차단·속도 제한·스팸 필터·운영자 검토·이의 제기. 운영자 조치의 시간·사유·결과 기록.
- Reddit 등 외부 콘텐츠는 2026-06-01 이후 사례를 조사 근거로 활용하되 무단 원문·사진·닉네임·댓글 복제/합성 후기 금지. 사례 수를 시장 발생률로 취급하지 않는다.
- 상업성 표시와 효능 주장 등 미국 대상 정책·관련 법률은 출시 전 검토. AI 모더레이션 도입은 운영비·필요성 검증 후.

## 수용 기준
협찬 표시 검증, 관계 은폐 신고, 긴급/일반 신고 분류, 차단·삭제 콘텐츠의 모든 노출 동기화, 재위반·이의 제기, 비공개 데이터 노출 차단, 오탐·운영 비용 측정.
