# PRD 03 — 채팅·경험 공유 동작

상태: **정책 확정 / 구현 미검증**

## 확정
- 일반 채팅·기존 답글을 그대로 유지. 추가 설문 강제 금지.
- 경험 공유는 **기존 채팅 입력창 근처의 선택 기능**. 별도 필수 후기 피드를 만들지 않음.
- 사용 여부·기간·결과 중심으로 시작, 해결 경험·조건·사진은 필요할 때 선택적. 건너뛰기 허용.
- 제품별 방은 정확한 제품/옵션 재사용, 주제별 방은 제품 필수 아님.
- 같은 경험을 다른 대화에 재사용하면 원본 ID 참조.
- 작성자 자기신고 vs 일반 의견 vs 미사용자 질문은 구분.

## 수용 테스트
1. 일반 채팅은 경험 정보 없이 정상 전송.
2. 선택형 경험 입력 취소 시 경험 레코드 없음.
3. 경험 전송 성공 시 원본과 메시지가 일관되게 저장; 한쪽만 남지 않음.
4. 실패 재시도는 중복 레코드를 생성하지 않음.
5. 기존 경험 다른 방 공유 시 원본 ID 유지.
6. 소유권 없는 수정/삭제 거부. 삭제/숨김 시 모든 연결 위치에 반영.
7. 작성 중 일반 채팅으로 전환하거나 네트워크 오류 시 초안 보존.
8. 공개하지 않은 피부 타입·사용 조건을 추정·노출하지 않음.
9. 모바일 웹/iOS에서 현재 탭 구조·대화 목록·제품 첨부 기능 회귀 없음.

기존 API와 서버 트랜잭션의 실현 가능성은 운영 DB 확인 전까지 미검증.
