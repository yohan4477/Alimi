# PRD 09 — Beauty Pick: 대화형 A/B 투표 (기능 가설)
작성: 2026-10-22 · 상태: **가설 / 서버 구현·실사용자 검증 전**

## 목적
뷰티 고민(립 컬러, 쿠션 호수, 블러셔 표현, 제품 선택)을 쉽고 빠르게 질문하며, 선택 이유와 후속 질문을 통해 새로운 맥락을 얻는다. 단순 인기투표·제품 추천 알고리즘이 아니다. 브랜드 v0.3, 경쟁 전략 v0.4의 하위 실험.

## 진입 구조
- 새 상단/하단 탭 없이 기존 방의 질문 작성 플로우에서 `일반 질문 / A·B 투표`를 선택.
- 사용 경험이 없어도 의견을 낼 수 있다. 투표 참여, 이유 작성, 채팅 모두 독립적으로 선택.
- 투표는 2개 선택지부터 시작; 제목, 설명, 사진/실제 제품/색상 정보는 필요시 선택.
- 작성자는 닉네임으로 시작; 회원가입/피부 프로필 강제 없음.

## 경험
1. 작성자가 고민과 A/B 선택지(해당하는 경우 이미지·색상)를 입력하고 질문을 전송.
2. 이용자는 A/B 또는 결과를 모름/경험 없음 등 상황에 따라 **기권/결과 확인**. 투표 없이도 대화 가능.
3. 선택 후 결과는 실제 응답 데이터만 표시; 0표는 0표, 조작된 가상 수치 금지.
4. 이유는 일반 대화 메시지로 남겨 원본 투표/선택지와 연결. 제품 사용 여부를 선택적으로 명시.
5. 실제 경험자의 이유를 발견하면 작성자에게 후속 질문 가능(응답 의무 없음).
6. 작성자는 종료·결정 여부를 선택적으로 업데이트; 구매/만족/효과를 자동 추정하지 않음.

## 투표 유형과 신뢰 라벨
| 유형 | 질문 | 데이터의 의미 |
|---|---|---|
| 시각/색상 선호 | 어느 색이 더 어울리는가 | 참여자의 미적 선호, 객관적 적합성 증명 아님 |
| 제품 선택 | 어떤 제품이 더 나은가 | 사용 여부 표시 없는 표는 성능 경험으로 취급 불가 |
| 메이크업 결과 | 두 표현 중 어느 쪽이 좋은가 | 촬영·조명·기기 색상 차이 고지 가능 |

'투표율'은 응답자 분모의 선택 비율이며 실제 제품 적합률/만족률을 의미하지 않음. 자기신고 사용 경험은 구매 인증 아님. 협찬/상업 관계 고지.

## 화면/상태
- UI-10 투표 작성: 일반 질문→A/B 전환, 옵션 추가·수정·삭제, 미입력 검증, 작성 취소 초안 보존.
- UI-11 투표 카드: 선택지 이미지/이름, 투표, 결과 보기, 투표 변경 정책(초기에는 1계정/식별자 1표, 변경 가능 여부 별도 결정), 로딩/실패/마감.
- UI-12 후속 대화: 선택 이유, 사용 여부(선택), 해당 경험 원본으로 질문, 답변 알림 통제.
- UI-13 이후 선택: 작성자의 선택·후속 결과 기록(모두 자발적).

## 데이터 모델 제안 (운영 스키마 확정 아님)
Poll(id,room_id,author_id,question,body,kind,status,created_at,closed_at?)
PollOption(id,poll_id,order,label,item_variant_id?,image_ref?)
Vote(poll_id,option_id,voter_id,created_at,updated_at?)
PollMessageRef(poll_id,message_id,option_id?)
PollOutcome(poll_id,author_id,selected_option_id?,reason?,observed_at?)
식별·투표 중복 방지는 서버 권한/RLS·RPC 검증 후 설계. 무단 이미지 재사용 금지.

## 수용·안전
- 투표 없는 일반 대화 경로 회귀 없음.
- 투표 전에 결과를 볼 수 있는지, 투표 변경/취소를 허용하는지 UI에 명확히 표현.
- 응답 0건이나 데이터 오류에 가짜 표·비율을 출력하지 않음.
- 해당 방의 권한을 벗어나 메시지/투표/이미지가 노출되지 않음.
- 가짜 참여/봇 표·운영자 위장 표 금지. 개인 얼굴·피부 사진 업로드 시 개인정보·초상권 보호/삭제.
- 지역/언어 별 제품과 이미지 확인, 320px 모바일 대응.

## 검증 실험
기존 일반 질문 vs A/B 투표를 같은 모집 채널에서 비교:
- 질문 작성 완료율, 첫 참여율, 후속 대화율
- '유용한 이유'가 달린 투표 비중, 질문 후 판단 변화
- 한 이용자의 반복 참여율과 부담/피로, 기권 비율
- 실제 채팅·제품 결과가 없는 상태에서 유용성을 과장하지 않음.
