# PRD 06 — 커뮤니티 퍼널·KPI

상태: **핵심 KPI·보고 주기 확정 / 계측 실수신 미검증**

## 확정 성과 체계
- **커뮤니티 핵심 선행 KPI = 유용한 답변을 받은 질문 비율.**
- 국가별(미국/한국) **주간 보고** 및 질문자/답변자 **D7 코호트**.
- 최종 사업성과는 승인·귀속된 **순제휴 수수료**, 취소·반품 차감. 판매처 클릭 = 매출 아님.
- 단일 강제 퍼널이 아닌 진입 경로별 코호트/분기: 방문 → 대화 발견 → 참여 → 도움·경험 공유 → 재방문 → 제품 판단/판매처 이동.

## 지표 정의 제안
| KPI | 분자 | 분모/조건 |
|---|---|---|
| 유용한 답변 도달률 | 관찰 기간 내 유용한 답변 확인된 질문 | 같은 기간 평가 대상 질문. 미평가 별도 집계 |
| 첫 발화율 | 대화 열람 뒤 첫 메시지 실제 전송 이용자 | 열람 이용자 |
| 경험 공유 완료율 | 실제 저장된 경험 전송 | 경험 공유 시작 |
| 답변 도달률 | 답변 >=1건 질문 | 해당 기간 질문, 스팸·운영자 테스트 분리 |
| 후속 대화율 | 답변 후 추가 대화 이어진 질문 | 답변 받은 질문 |
| D7 참여 재방문 | 정의된 7일 차 기간에 돌아와 유효 행동한 코호트 이용자 | 첫 유효 참여 코호트; 익명 ID 유실 주의 |
| 대화→제품 상세 | 대화 출처가 확인되는 제품 상세 진입 이용자 | 대화 열람 이용자 |
| 확정 순제휴수익 | 승인 수수료에서 조정 차감 | 해당 정산기간, 국가·플랫폼 일치 |

## 이벤트 명세 제안
community_view, room_impression, room_open, message_sent, experience_shared, reply_received, reply_helpfulness, notification_open, product_open, merchant_click. 기존 `dist/events.js`의 실제 이벤트 이름/전송 흐름과 매핑 감사 선행. event_id 중복제거, region/locale/channel 구분. 원문 메시지·피부 정보·익명 비밀값 분석 이벤트 송신 금지.

## 가드레일
미답변율, 메시지 스팸/신고, 작성 이탈, 차단, 운영비, 무응답, 부정 후기 편향, 사용성 실패. 미측정은 0과 구분. 표본·기간·목표 수치는 실험 전에 확정하며 현재 실사용자 실험 결과 없음.
