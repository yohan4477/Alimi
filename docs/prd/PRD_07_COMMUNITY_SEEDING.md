# PRD 07 — 초기 커뮤니티 대화 활성화 운영 (초안)

상태: **기획 제안 / 사용자 검토 대기 / 실험 미실시** (2026-10-21)

## 목적
초기 방문자가 가짜 후기나 허위 대화 없이 진짜 질문·경험·후속 답변을 찾게 한다. Reddit보다 우월하다는 주장은 실험 전 금지.

## 첫 실험
- 문제 후보: 건성 피부에서 쿠션의 들뜸·건조함. 가장 빈번한 시장 문제라고 주장하지 않는다.
- 기존 주제별·제품별 공개 방 및 추천/대화방/발견 상단 탭, 커뮤니티/탐색/내 활동 하단 탭 유지.
- 운영자가 **운영자임을 공개한 질문** 게시. Reddit 원문·사진·닉네임 무단 복제, 가짜 후기·가짜 참여자 수 금지.
- 직접 사용 경험이 있는 초기 답변자를 모집; 사용 여부·기간·결과·해결 조건은 본인이 선택적으로 공개.
- 비회원 열람과 익명 닉네임 참여 유지. 다른 사람의 질문/답글을 읽고 추가 질문할 수 있어야 함.
- 제품 사진은 제품별 방에만 검증된 해당 제품 사진, 주제별 방은 기본 아이콘.

## 운영자 개입 원칙
| 상황 | 대응 |
|---|---|
| 막 등록된 일반 질문 | 원칙적으로 개입 안 함 |
| 의미가 불명확한 질문 | 필요한 경우 운영자 표시 후 한 가지 보충 질문 |
| 정해진 시간 내 답변 없음 | 운영자가 답변 가능한 실제 경험자에게 연결 요청. 응답을 보장하지 않음 |
| 자연스러운 소비자 대화 진행 | 운영자 개입 안 함 |
| 스팸·위협·개인정보 노출 | PRD 05에 따른 차등 신고/운영 조치 |

답변 대기시간 임계값은 실험 전에 정하며 현재 수치 미확정. 자동 LLM 진행자 도입은 P0 아님.

## 14일 파일럿 제안
- 1~3일: 주제·초기 답변자·동의 및 모집·공개 운영자 질문 초안
- 4~5일: 기존 실제 방 구조 안에서 게시·첫 응답 준비. 빈 방은 빈 상태로 노출
- 6~10일: 실제 질문자 초대 및 대화 관찰
- 11~14일: 후속 질문, 인터뷰, 재방문 신호 확인
- 10~15명 사용성 관찰은 **제안치**이고 시장 대표성·통계적 검증이 아님.

## 평가와 중단 조건
핵심: 유용한 답변을 받은 질문 비율. 보조: 첫 유용 답변 시간, 자발적 후속 질문, 질문자/답변자 D7(관찰 기간 충족 시), 운영자 개입 비중, 신고·스팸·운영 시간.
운영자 답변·소비자 답변 분리, 미평가/무응답 분리, 테스트/데모 활동 제외. 운영 지원 없이는 대화가 생기지 않거나 질문·후기 사칭이 필요하다면 확대하지 않는다.

## 선행 조건·미정
- 미국 우선 초기 답변자 확보 및 자발적 참여 동의
- 첫 답변의 유용성 정의/평가 기한/무응답 에스컬레이션 기준
- 신고/운영 담당 및 실제 처리 가능량
- 운영자와 초기 답변자의 상업적 관계 고지(PRD 05)
- 실제 웹/iPhone 경로, 이벤트 전송과 국가별 코호트 검증

**코드·DB·운영 게시·자동 알림 변경 승인 아님.** [PRD 목차](README.md) · [기획박스 #26](https://github.com/yohan4477/Alimi/issues/26).
