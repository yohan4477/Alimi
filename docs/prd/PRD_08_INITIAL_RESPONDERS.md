# PRD 08 — 초기 답변자 확보 파일럿 (기획 초안)
작성: 2026-10-21 · 상태: **제안 / 모집 실행 전 / 사용자 승인 대기**

## 문제와 목표
빈 커뮤니티에서 실제 신규 질문에 진짜 경험자의 유용한 답변이 달리도록 설계한다. 가짜 댓글, 가공 후기, 인위적 참여 수/인기 표시 금지. 운영자/협찬/인센티브 이해관계 공개.

## 답변자 후보
- 일반 미국 뷰티 소비자: Sephora·Ulta·드러그스토어 등 다양한 브랜드 직접 사용 경험.
- 한국 제품 경험자: K-뷰티 실사용 경험. 아시아인일 필요 없음.
- 질문/답변에 적극적인 이용자: 팔로워 수보다 자발적 참여와 구체적 경험을 우선.
- 특성은 중복 가능. 인종으로 피부톤·제품 적합성 추정 금지.

### 10명 파일럿 모집 배분 제안(통계 표본 아님)
일반 뷰티 사용 경험 4 / K-뷰티 사용 경험 4 / 적극적인 질문·답변자 2. 필요시 스킨케어/메이크업 균형 및 다양한 피부톤·사용 환경 포함. 실제 미국 거주 여부/경험은 동의하에 확인. 대학/지인/관심사 커뮤니티의 선택 편향 기록.

## 채널 가설
Reddit(각 커뮤니티 홍보/모집 규칙 준수), TikTok/Instagram(스팸 DM 금지), 미국 대학 커뮤니티(연령·학교 편향), 기존 초대링크(초기 유입 한계), 지인(호의 편향). 초기 2개 채널만 비교 제안; 실제 모집 채널 미확정.

## 동기·보상 원칙
직접 경험으로 타인을 도울 가치, 같은 관심사의 후속 대화, 초기 실험 참여 자체. 정액 인터뷰 사례비는 가능하나 **후기 긍정성·추천 수·판매 클릭을 조건으로 보상하지 않음**. 모든 물질적 이해관계와 운영자 정체 공개.

## 질문→답변 운영 프로토콜
1. 실제 이용자가 질문 (운영자 질문은 운영자임을 표시).
2. 답변 가능 주제/제품과 자발적 참여 동의를 확인.
3. 운영자가 합의된 연락 방식으로 초기 답변자에게 질문 연결 요청.
4. 실사용 답변자가 사용 조건·기간·결과를 선택적으로 공유.
5. 질문자와 답변자의 후속 대화는 자발적으로 진행; 운영자 상시 진행 금지.
6. 미답변 질문을 확인하되 보장된 응답/허위 활동은 표시하지 않음.
위험 게시물은 PRD 05 기준 즉시 처리.

## 14일 실험 제안
1~3일 실제 답변자 모집/동의, 4~5일 실제 채팅 경로와 운영자 공개 질문 준비, 6~10일 질문자 초대 및 답변·후속 관찰, 11~14일 인터뷰·재방문·운영 부담 측정.

## 핵심 KPI
- 유용한 답변을 받은 질문 비율(PRD 06의 핵심 KPI)
- 질문→첫 유용 답변 소요 시간
- 운영자 개입 없이 진행된 후속 질문률
- 재참여 답변자 비율과 답변당 운영 시간
모든 수치는 **질문자/답변자·운영자/일반 회원·보상 여부·미평가/미답변** 구분. 목표 수치·모집 실행·사례비 예산 아직 미확정.

## 필수 게이트
연락·참여 동의와 개인정보 수집 최소화, 커뮤니티별 홍보 규칙, 청소년/성인 대상 범위, UGC 신고 대응, 미국/한국 지역 구분, 익명 참여·알림 실동작 확인. 모집/메시지 전송/코드/DB/배포는 아직 실행하지 않음.
