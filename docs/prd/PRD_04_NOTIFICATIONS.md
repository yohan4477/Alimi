# PRD 04 — 앱 내 알림·딥링크·재방문

상태: **정책 확정 / 구현 미검증**

## 정책
- 초기에는 **앱 내 알림**만 우선. 푸시는 별도 동의·토큰·전달 검증 후 확장.
- 내 질문에 달린 직접 답변, 내 경험·메시지의 후속 질문을 알림 대상으로 제한. 저장한 모든 방 새 메시지나 가격 변동 알림 제외.
- 짧은 시간 내 같은 대화의 연속 답글은 묶어서 표시. **묶음 시간(예: 5분)은 실험 제안값이며 최종 미확정**.
- 동일 event_id 중복 생성 방지, 자기 자신에게 알림 금지.
- 알림·공유 링크는 room/message/reply ID 및 접근 권한으로 **정확한 답글 위치**에 이동.
- 삭제·차단·신고·비공개·지역 간 접근 제한을 확인하고 비공개 내용을 미리보기에 노출하지 않음.
- 익명 세션이 유실된 경우 타인 기록 접근 불가. 앱 내 읽음·재접속 후 상태는 서버 기준 검증.

## 수용 기준
동일 사건 알림 1회; 연속 답글 묶음; 삭제된 타깃 대체 상태; 메시지 위치 정확도; 앱 재시작 후 읽음 동기화; 권한 없는 접근 차단; 푸시 권한 요구 없이 기본 동작.
