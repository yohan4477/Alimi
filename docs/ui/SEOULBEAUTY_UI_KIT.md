# SeoulBeauty UI Kit v0.1 — Conversation & Beauty Pick

상태: 디자인 기준 라이브러리 **초기 구현**. 지금 채팅에서 사용자가 선호한 UI(깨끗한 흰 배경, 밝은 파란색 강조, 작은 회색 보조 글자, 부드러운 회색 대화 버블, 둥근 A/B 투표 카드, 컴팩트 입력창)를 웹용 CSS 클래스로 변환한 초안. 원본 웹앱의 로고와 3탭은 변경하지 않는다.

## 파일
- `dist/ui-kit/seoulbeauty-ui.css`: 외부 종속성 없는 scoped CSS (`.sbui` 안에서만 작동)
- `dist/ui-kit/demo.html`: 버튼/투표/대화/입력창을 확인하는 별도 정적 데모
- 이후 공통 버튼/카드/상태 변화 구현 시 본 키트에서 재사용, UI-01~UI-09 명세 연계

## 컴포넌트 계약
| 컴포넌트 | 기본 상태 | 다른 상태 | 접근성 |
|---|---|---|---|
| ChatHeader | 방 이름·뒤로가기 | 로딩·메뉴 | 제목, 버튼 레이블 |
| MessageBubble | 닉네임·본문·시간 | 내 글·실패·삭제 | 텍스트 우선 |
| PollCard | 제목·A/B 선택·기권 | 선택·마감·0표·오류 | 키보드 선택, aria-pressed |
| PollOption | 텍스트·선택 이미지 | 선택/비활성 | 44px 최소 터치 |
| ExperienceBadge | 자기신고 사용 조건 | 정보 없음/비공개 | 구매 인증 오해 금지 |
| Composer | 일반 메시지 | 답장·첨부·경험 공유 | 선택형 기능, 초안 유지 |
| FollowupLink | 원본 경험자에게 답글 | 응답하지 않음·알림 끔 | 응답 의무 없음 |

## 금지 사항
새로운 하단 탭이나 상단 메인 탭을 추가하지 않는다. 임의 참여자 수·투표율·리뷰 점수·실제 효과를 생성하지 않는다. 선택 투표를 사용 후기로 취급하지 않는다. 가입·피부 정보·투표 참여·후기 입력을 강제하지 않는다. 원본 로고를 재작성하지 않는다.

## 개발/QA
사용자가 승인한 것은 **대화형 투표 UI의 디자인 스타일**이며 색상값은 현재 대화 UI의 근사치이므로 실제 iPhone 실기기에서 시각 확인 후 보정한다. 별도 데모만 제공하고 기존 서비스에는 연결하지 않는다. PR 검토 후 화면에 점진 적용한다.
