# SeoulBeauty 모바일 사용자 여정 디자인 규격 v1.0 (검토안)
2026-10-21. CX 01~06·PRD 01~08 기준. **이미지/PPT 수정 전 공통 규격**. 실제 구현·배포 증거 아님.

## 반드시 유지
- 웹 하단 탭 **커뮤니티 / 탐색 / 내 활동**, 정확히 3개. `dist/index.html`의 `#tabbar` 확인. 임의로 홈/알림/마이를 새 하단 탭으로 추가 금지.
- 커뮤니티 홈 상단 **추천 / 대화방 / 발견**, 정확히 3개. `dist/chat.js`의 `HOME_TABS=['rec','rooms','discover']` 확인.
- 대화방 탭 안의 **주제별 / 제품별**은 상단 메인 3탭이 아닌 내부 탐색 선택. 브랜드별/전체를 상단 메인 탭으로 신설하지 않음.
- 기존 SeoulBeauty 로고·브랜드 색·폰트·지역 선택·검색·알림 접근 경로와 내 활동의 기존 내부 구조 유지. 채팅방 상세·경험 작성 모달·제품 상세는 홈 메인 상단 탭이 없는 화면일 수 있으므로 **존재하지 않는 탭을 억지로 추가하지 않음**.
- 알림은 독립 화면/기존 접근점. 하단 탭 추가 금지. 가격 추적/가격 이력/목표가/가격 변동 알림 제거.
- 미국/한국 지역·영문/국문을 섞지 않고 지역/언어별 문구를 점검.

## 콘텐츠·이미지 정책
- **주제별 채팅방**: 관련 주제 아이콘. 임의 제품 사진을 대표 이미지로 자동 사용 금지.
- **제품별 채팅방**: 검증된 해당 제품 이미지, 없으면 기본 제품 아이콘. 임의 제품으로 대체 금지.
- **브랜드별 채팅방**: 권리 확인된 브랜드 로고, 없으면 텍스트.
- 실제 게시글이 없으면 빈 상태. 참여 수·별점·후기 수·가격·타인 메시지·제품 효능을 만들어 운영 화면처럼 제시 금지. 모든 시안의 합성 데이터는 '예시'로 표기.
- 사용 경험은 직접 사용 **자기신고**, 구매 인증이 아님. 사용자 선택 조건만 태그로 표시, 긍정/부정/해결 여부를 함께 허용.

## 슬라이드 공통 형식
- 16:9, 단계당 1장, 동일 폰 디바이스 크기·베젤·타이포 크기·상하 좌우 여백, 단계 번호/화살표 통일.
- 스마트폰 3~5개는 모바일 화면 비율 유지, 잘린 탭/텍스트 없게 확인. 화면 자체에 모든 정보가 있으면 외부 설명 중복 추가 금지.
- 이미지 생성 시 임의 텍스트·탭·수치가 발생할 수 있으므로 **사람이 결과를 대조한 후에만 PPT 삽입**. 실제 구현 증거로 사용하지 않음.
- 향후 IR 실제 화면은 재구성한 이미지가 아니라 별도의 원본 스크린샷 사용.

## 단계별 정보 구조
1. **첫 방문**: 기존 커뮤니티 홈 직접 진입, 서비스 설명 1~2줄, 실제 대화 노출·읽기 전 로그인/설문 없음.
2. **대화 탐색**: 추천/대화방/발견, 대화방 내부 주제별/제품별, 제목+실제 최근 대화 1줄+확인된 고민 태그. 상단 탭 혼동 금지.
3. **채팅 참여**: 읽기→익명 닉네임 자유 작성/답글, 계정 로그인 강제 없음. 경험 설문 자동 팝업 금지.
4. **경험 공유**: 채팅 입력창 근처 선택 진입, 사용 여부·횟수/기간·결과, 필요한 경우만 상세 조건. 원본 경험 참조.
5. **제품 발견**: 제품 기본 정보→직접 사용 경험/관련 대화→하단 구매처. 조건 태그 기반 비교, 가짜 평점·확정 효능 금지.
6. **재방문**: 내 질문/경험의 직접 답글 앱 내 알림→해당 메시지 정확한 위치→후속 질문. 기존 내 활동/저장/공유. 가격 알림 금지.

## 검수 체크리스트

- [ ] 상세화면에 가상의 메인 탭을 넣지 않음
- [ ] 주제별/제품별/브랜드별 이미지 정책 준수
- [ ] Reddit 대비 '사용 조건·결과·해결 방법·후속 질문' 장면 존재
