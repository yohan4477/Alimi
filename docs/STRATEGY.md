# SeoulBeauty 전략 — 초기 K-뷰티 × 고민 커뮤니티

기준: **2026-10-19 KST, 사용자 확정 결정**. [제품 비전](PRODUCT_VISION.md) · [서비스 기획](SERVICE_PLAN.md) · [실행 로드맵](ROADMAP.md) · [관리 대시보드](PRODUCT_STATUS.md) · [기획박스 #26](https://github.com/yohan4477/Alimi/issues/26).

## 1. 확정된 전략 방향

**초기 핵심 타깃:** 미국의 **18~24세 중 K-뷰티에 관심이 많고 피부 관리·메이크업에 구체적인 고민이 있는 이용자**. 넓게는 10~20대가 관심 고객층이지만, 초기 파일럿은 18세 이상으로 운영하고 미성년자로의 확장은 개인정보·사진·외모 평가 및 피부 조언 관리 기준을 마련한 뒤 검토한다.

**고객 가치:** K-뷰티에 대한 관심으로 유입된 사용자가 **자신과 비슷한 피부 고민·메이크업 취향의 사람**을 만나 질문·경험을 나누고, 대화에 등장하는 제품의 정확한 정보·옵션·브랜드·판매처를 확인한다.

**포지셔닝:** 「K-뷰티 관심자 전용 제품 카탈로그」도 「주제가 무제한인 종합 자유 채팅」도 아닌 **K-뷰티로 시작하는 고민 중심 뷰티 커뮤니티**. 초기 콘텐츠·유입에는 K-뷰티를 집중 활용하되, 회원이 다른 국가·브랜드 제품을 이야기하는 것은 제한하지 않는다.

**최종 사업 목표:** **제휴 링크를 통해 발생하고 실제 승인·귀속된 수수료 매출의 성장**. 커뮤니티의 대화량·DAU·링크 클릭 수는 목적이 아니라 수익을 만드는 선행 지표다. 신뢰와 유용한 경험이 훼손되면 지속 수익도 약화될 수 있으므로 제품 추천을 강제하지 않는다.

이는 사용자의 확정된 전략 선택이다. **이 타깃이 실제 전환율·유지율에서 더 유리하다는 주장은 아직 검증 가설**이다.

## 2. 고객 경험과 차별화

1. **유입:** K-뷰티 브랜드·제품, 여드름/민감성/피부 톤, 쿠션 호수/틴트 등 구체적인 피부·메이크업 고민을 통해 방문한다. 스킨케어와 메이크업에 동시 관심이 있을 수 있으며 둘 다 복수 선택 가능해야 한다.
2. **활성화:** 처음 방문 시 피부 타입·관심 고민을 선택적으로 고르거나 건너뛰고, 이미 대화가 있는 방·질문을 찾는다.
3. **신뢰·재방문:** 비슷한 조건을 가진 다른 사용자와 실제 경험을 교환하고, 답변 확인·후속 대화 때문에 돌아온다.
4. **상품 발견:** 사용자가 대화에 제품·정확한 옵션을 첨부하면 제품 상세, 브랜드 탐색, 관련 대화로 자연스럽게 이동한다.
5. **수익화:** 사용자가 원할 때 **제휴임을 알리는 판매처 링크**로 이동한다. 클릭과 구매, 주문 귀속, 취소·반품, 승인된 수수료는 구분한다.

기존 **Community / Search / My Activity** 탭, 글·실시간 채팅, 상품 카드 첨부·브랜드 탐색·저장 흐름은 보존한다. 추천방·온보딩·상세 연결은 별도 [서비스 기획](SERVICE_PLAN.md)에서 설계하고, 전략 문서 업데이트만으로 앱 구현이나 배포를 완료했다고 하지 않는다.

## 3. 사업 성과 지표의 인과 구조

**최종 KPI:** 관찰 기간에 **승인된 순제휴 수수료 매출**. 클릭 수나 예상 주문액을 매출로 보고하지 않는다.

**단순화한 매출 분해식:**

> 승인 순제휴 수수료 ≈ 제휴 링크 클릭 수 × 클릭→승인 주문 전환율 × 승인 주문 평균 결제금액 × 실효 수수료율

제휴 클릭 수는 유입 규모, 방문 빈도, 제품 노출률과 링크 클릭률의 영향을 받는다. 취소·반품과 제휴사 귀속 조건은 주문 전환·실효 수수료에 반영한다. 복수 주문과 추적 기간 차이 등은 실제 제휴사 데이터 정의를 따른다.

| 계층 | 지표·정의(제안) | 전략 레버 | 현재 상태 |
|---|---|---|---|
| 최종 성과 | **승인 순제휴 수수료 매출** = 승인·귀속 수수료 − 취소·반품 등 차감 | 전체 퍼널 최적화 | 미연결·미측정 |
| 트래픽 | 신규 순방문자, 유입 채널, 추천·공유 유입 | K-뷰티 및 고민 관련 콘텐츠, 초대·검색 | 미측정 |
| 활성화 | 첫 유의미 대화 참여율 = 신규 이용자 중 질문·댓글·실제 채팅 발화자 / 해당 신규 이용자 | 고민 맞춤 추천, 첫 질문·답변 경험 | 미측정 |
| 리텐션 | 신규 참여자 D7 재방문율, 반복 대화 참여자 | 답변·알림·대화 복귀·관계 | 미측정 |
| 상품 발견 | 대화→상품 상세 이동률, 정확한 제품·옵션 첨부율 | 대화 중 상품 카드, 브랜드·검색 연결 | 미측정 |
| 구매 퍼널 | 방문→제휴 클릭률, 제휴 클릭→승인 주문 전환율, 평균 주문금액 | 관련성 높은 실제 후기, 상품정보·판매처 연결 | 클릭 이벤트 일부 존재, 실제 주문·귀속 미검증 |
| 트래픽 수익성 | **순방문자 1,000명당 승인 제휴 수수료** = 수수료 / 순방문자 × 1,000 | 단순 DAU 증가와 구매 의도 차이 구분 | 미측정 |
| 가드레일 | 무응답 질문, 첫 유용한 답변 시간, 신고·광고/스팸, 오류·반품 | 커뮤니티 신뢰·운영 품질 | 미측정 |

**리텐션은 매출 공식에서 유입과 별도로 기계적으로 곱하지 않는다.** 반복 방문이 제품 노출·클릭 기회를 어떻게 만드는지 코호트로 검증한다. KPI의 정확한 기간·이벤트 정의·동일 사용자 판별·테스트 트래픽 제외 규칙을 사전 확정한다. 실적값과 목표치는 아직 없다.

## 4. 검증 우선순위

| 우선 | 검증할 전략 질문 | 관찰 기준 | 상태 |
|---|---|---|---|
| P0 | K-뷰티 관심 × 피부·메이크업 고민 사용자들이 기존 K-뷰티 일반 방문자보다 첫 대화에 참여하는가? | 유입→방 입장→첫 유의미 발화 | 미실험 |
| P0 | 비슷한 고민의 사용자에게 제때 유용한 답변을 제공할 수 있는가? | 답변률·답변까지 걸린 시간·첫 주/다음 주 재방문 | 미실험 |
| P0 | 대화에 등장한 제품이 실제 클릭·구매로 연결되는가? | 상품 노출→상세→제휴 클릭→귀속 주문·확정 수수료 | 주문/정산 연동 미검증 |
| P1 | 피부 문제 해결형과 메이크업 추천형 중 트래픽 수익성이 어디서 높은가? | 주제별 D7, 1,000명당 수수료·전환 | 미실험 |
| P1 | 가입 요구·고민 입력 시점이 이탈을 만드는가? | 선택형 온보딩 vs 먼저 둘러보기 | 미실험 |

초기 운영에서는 사용자가 찾을 수 있는 유용한 대화·답변을 먼저 확보한다. **사용자는 주제나 관심사에 제한 없이 방을 자유롭게 생성할 수 있고**, 추천은 이미 생성된 방 가운데 관련 대화를 찾아주는 별도 기능이다. ‘방 추천을 위한 초기 운영 집중’이 사용자의 방 생성 제한을 의미하지 않는다. 방문 수가 적을 때는 표본 부족을 명시하며 가설을 검증된 사실로 승격하지 않는다.

## 5. 경계와 보류 항목

- **핵심 유지:** K-뷰티 브랜드·상품 탐색, 고민 기반 대화, 글·실시간 채팅, 상품·옵션 연결, 판매처 이동, 익명·선택형 피부 관심사.
- **미검증 설계:** 피부/메이크업 관심사 온보딩, 추천 채팅방, 사진·공유, 문구 완전 분리(ko/en) 등의 실제 제품 동작. 구현·테스트·배포를 각각 확인한다.
- **현재 제외:** 소비자 가격 이력·목표가·가격 알림·가격 추적 서비스 포지셔닝(D-012). 실제 현재 가격과 판매처 정보는 지원 가능하다.
- **후속 판단:** 전체 뷰티 관심자·미성년층으로 타깃 확대, 시술·병원 연결, 광범위한 국가·상품군 확장, 기업용 리포트·API.
- **신뢰:** 제휴 관계를 투명하게 표시한다. 피부 특성·인종·성별 등을 사진이나 아바타에서 추정하지 않고 개인정보를 불필요하게 노출하지 않는다.

## 6. 운영 규칙

전략 방향·타깃·매출 KPI는 이 문서와 관리자 **전략** 탭을 원본으로 관리한다. 화면별 구조와 수용 기준은 [SERVICE_PLAN](SERVICE_PLAN.md), 실제 구현·검증·배포 상태는 [PRODUCT_STATUS](PRODUCT_STATUS.md)와 Issues·PR에서 따로 관리한다. 전략 변경은 매출 실측이나 고객 검증을 뜻하지 않는다.
