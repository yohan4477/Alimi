고객 문제
내 조건에 맞는 경험을 찾기 어렵고, 대화에서 본 상품을 다시 찾아야 한다.실제 사례·불편의 빈도 확인 필요
차별화
질문·후속 대화의 맥락을 정확한 상품·옵션에 연결한다.기능 존재와 경쟁 우위 입증은 별개
초기 성장
작은 집단 · 반복 질문 주제 하나 · 초기 답변 운영대화가 유용하고 다시 올 이유가 생기는지 검증
수익 모델

대화에서 상품으로, 다시 대화로

커뮤니티→질문·답변→상품 확인→저장·구매처→재방문
목표 경험 · 각 항목을 열면 화면 구성과 확인 기준 표시
커뮤니티 홈 · 대화할 곳 찾기
  • 관심 주제·최근 대화·질문 진입을 중심으로 배치
  • 빈 화면·로딩·오류·재시도를 구분
  • 검색·브랜드에서 들어와도 관련 대화로 연결
대화 · 익명으로 묻고 답하기
  • 익명 닉네임과 간단한 작성·답변 흐름
  • 사진형 프로필은 필수로 두지 않는 안을 우선 검토
  • 글·댓글과 실시간 채팅의 역할 구분
  • 실패 시 입력을 보존하고 재방문 시 문맥 유지
상품 첨부 · 대화 중 바로 보여주기
  • 상품 검색 → 정확한 상품·옵션 선택 → 사진·이름이 있는 카드
  • 카드를 열면 해당 상품 상세와 관련 경험 확인
  • 첨부 취소·검색 결과 없음·오류·오연결 방지 확인
상품 상세 · 이해하고 선택하기
  • 상품 설명·옵션·후기·관련 대화·현재 가격·판매처
  • 직접 작성한 분류 설명과 허용된 공식·판매처 설명 구분
  • 미확인 배송비·세금·관세·재고를 확정 조건으로 표시하지 않음
  • 제휴 고지와 실제 판매처 이동 확인
브랜드·저장 · 다시 찾기
  • 로고·이름·브랜드 필터와 실제 상품 목록 연결
  • 모바일 간격·터치 영역·선택·로딩·오류 확인
  • 상품 저장→재방문 유지, 가격 추적 요청 없음
  • 기기 내 스냅샷과 최신 판매 조건의 차이 표시
검증 후 결정 · 사진·피부 정보·번역
  • 사진은 발색·사용 경험 설명에 추가 효용이 있는지 확인
  • 피부 타입·톤·고민은 선택 입력 검토
  • 번역 확대·개인화·리워드는 별도 판단
  • 기존 코드 존재와 실제 검증·출시 상태는 구분
