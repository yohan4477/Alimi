K-뷰티에 관심 있고,
피부·메이크업 고민을 나누고 싶은 사람들부터

SeoulBeauty는 비슷한 고민의 사람들과 경험을 나누고, 대화 속에서 실제 제품을 발견해 구매까지 연결하는 커뮤니티다.

타깃 · 포지셔닝

초기 고객
미국 18~24세 중 K-뷰티 관심이 많고 피부 관리·메이크업에 구체적인 고민이 있는 이용자10~20대 관심층 중 첫 검증 세그먼트. 미성년층으로의 확대는 별도 보호·운영 검증 뒤 결정.
사용 이유
내 피부 타입·고민·메이크업 취향과 비슷한 사람에게 묻고 실제 사용 경험을 듣는다.K-뷰티 관심으로 들어오고, 고민 해결과 관계·새로운 대화로 다시 방문한다는 가설.
차별화
고민별 대화와 정확한 상품·옵션 카드, 브랜드·판매처 연결을 하나의 흐름으로 제공초기 콘텐츠는 K-뷰티에 집중하지만 다른 브랜드의 언급·후기를 막지 않는다. 경쟁 우위는 실험으로 검증.
성장 방식
고민·K-뷰티 콘텐츠로 신규 유입 → 비슷한 사람과 대화 → 답변·관계로 재방문 → 자연스러운 제품 발견초기에는 소수의 활발한 방에 집중한다. 무인 채팅방 증식과 무리한 구매 유도는 지양.

화면별 변경 요소 · 사용자 행동 · KPI

첫 방문 · 신규
기기 언어 확인 → Skincare / Makeup 동시 복수 선택 → 선택 분야별 세부 고민 복수 선택 → 추천방 보기. 추천은 현재 사용자 생성 공개 방을 찾는 기능이며 전체 탐색·방 만들기는 독립적으로 가능. 건너뛰기·뒤로가기 허용. 피부 타입·톤 입력은 선택형 후속 정보.KPI: 온보딩 단계별 완료·이탈, 스킨케어만/메이크업만/둘 다/미선택 비율, 두 분야 교차 고민 선택률. 선택값 비공개·인구 특성 추정 금지.
Community 홈 · 수정
기존 참여 대화 아래 선택 고민과 일치하는 **사용자 생성 공개 방** 추천. 두 분야 선택 시 각 분야·교차 고민 방을 함께 보여주고, 전체 방 탐색·검색·자유 방 생성은 상시 제공. 인기 대화·제품·질문 보존.KPI: 분야 선택 조합별 추천방 노출→입장·첫 유의미 발화·D7. 추천 이유와 실제 활동 기준을 구분해 표시.
채팅방 · 수정
사용자가 자유 생성한 방의 고민·분야 태그와 추천 이유 표시. Posts/Live Chat·제품 첨부 유지. 새 방도 검색/탐색에서 발견되며 추천 엔진은 가짜 방을 자동 생성하지 않음.KPI: 조합별 방 입장→첫 메시지, 답변율·응답 시간, 대화→제품 상세·제휴 클릭(실측 미측정).
Search·브랜드 · 유지+연결
기존 브랜드 로고·상품 필터·검색 유지. 상품에서 관련 고민 대화방으로 이동, 채팅에서 상품 상세로 복귀하는 양방향 경로 강화.KPI: 상품→대화 이동률, 대화→상품 상세 이동률, 정확한 옵션 선택률.
상품 상세 · 수정
기존 설명·옵션·후기·현재 가격·판매처 유지. 관련 대화 링크를 더 잘 보이게 배치하고 사용자 후기와 공식 설명 구분.KPI: 관련 대화 열람률, 상품 저장률, 판매처 이동률. 클릭을 주문으로 간주하지 않음.
My Activity · 수정
기존 참여 대화·저장 상품·게시글 유지. Skincare·Makeup 각각의 선택과 세부 고민 수정·초기화 추가, 피부 타입·톤은 선택형 추가 정보.KPI: 관심사 수정 후 추천 변화, 선택 조합별 D7 재방문율·대화 재참여율.
공유 · 연결
기존 대화·상품에 친구 초대/공유 경로를 연결. 초대받은 사람은 해당 콘텐츠로 바로 이동.KPI: 공유 클릭률, 공유 링크 유입률, 초대 유입자의 첫 대화 참여율.
언어 · 전 화면
한국어·영어 시스템 문구와 기본 채팅방 정보를 분리. 선택한 언어 유지, 상품 고유명과 사용자 작성 원문은 보존.KPI: 언어별 온보딩 완료율·첫 참여율·누락 번역 건수. 기존 i18n 체계를 확장하며 탭 UI를 교체하지 않음.

추천 기준(기획): 사용자가 자유롭게 생성한 실제 공개 방 중 선택 고민·관심 분야·최근 활동 기반으로 추천. 둘 다 선택하면 각 분야·교차 고민 방 고려, 일치 방 없으면 전체 탐색·직접 방 생성·인기 대화. 고정 방 강제 없음. 신규 KPI 미측정.
