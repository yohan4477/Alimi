피부 고민 선택 → 맞춤 대화 → 상품 발견 → 재방문

기존 Community · Search · My Activity 탭과 게시글/실시간 채팅, 상품 첨부 흐름은 유지한다. 아래는 신규 기획이며 실제 배포·계측 완료를 뜻하지 않는다.
언어 선택→피부 타입·고민 선택→관련 채팅방 추천→질문·답변→상품·브랜드→재방문·초대

화면별 변경 요소 · 사용자 행동 · KPI

첫 방문 · 신규
기기 언어 기본값 → 피부 타입 단일 선택 → 피부 고민 복수 선택 → 추천방 보기. 건너뛰기·나중에 변경 가능.KPI: 온보딩 시작 대비 완료율, 단계별 이탈률, 추천방 진입률. 피부 정보는 선택값이며 인종·나이·성별 추정 금지.
Community 홈 · 수정
기존 참여 대화 바로 아래 '나와 비슷한 사람들의 대화' 추천 카드 추가. 활발한 대화·언급 상품·최근 질문·전체 주제는 보존.KPI: 추천 노출 대비 방 입장률, 첫 질문·댓글·채팅 참여율, 기존 인기방 대비 참여율.
채팅방 · 수정
기존 주제방에 피부 고민/타입 태그와 추천 이유 표시. Posts와 Live Chat 구분 및 상품 첨부는 그대로 유지. 빈 방 양산 방지.KPI: 방 입장→첫 메시지 전환율, 유용한 답변 비율, 첫 유용한 답변 시간, 무응답 질문 비율.
Search·브랜드 · 유지+연결
기존 브랜드 로고·상품 필터·검색 유지. 상품에서 관련 고민 대화방으로 이동, 채팅에서 상품 상세로 복귀하는 양방향 경로 강화.KPI: 상품→대화 이동률, 대화→상품 상세 이동률, 정확한 옵션 선택률.
상품 상세 · 수정
기존 설명·옵션·후기·현재 가격·판매처 유지. 관련 대화 링크를 더 잘 보이게 배치하고 사용자 후기와 공식 설명 구분.KPI: 관련 대화 열람률, 상품 저장률, 판매처 이동률. 클릭을 주문으로 간주하지 않음.
My Activity · 수정
기존 참여 대화·저장 상품·게시글 유지. 내 피부 타입·고민 편집 및 추천 재설정 추가.KPI: D7 재방문율, 참여 대화 재방문율, 관심사 수정 후 추천방 참여율.
공유 · 연결
기존 대화·상품에 친구 초대/공유 경로를 연결. 초대받은 사람은 해당 콘텐츠로 바로 이동.KPI: 공유 클릭률, 공유 링크 유입률, 초대 유입자의 첫 대화 참여율.
언어 · 전 화면
한국어·영어 시스템 문구와 기본 채팅방 정보를 분리. 선택한 언어 유지, 상품 고유명과 사용자 작성 원문은 보존.KPI: 언어별 온보딩 완료율·첫 참여율·누락 번역 건수. 기존 i18n 체계를 확장하며 탭 UI를 교체하지 않음.

추천 점수 초안: 고민 일치 60% · 타입 일치 30% · 활성도 10%. 실제 실험으로 조정. 모든 신규 KPI는 현재 미측정.

첫 방문 · 피부 타입·고민 선택 → 채팅방 추천
  • 첫 방문 시 언어별 피부 타입 단일 선택, 피부 고민 복수 선택. 건너뛰기 및 사후 수정 제공
  • 기존 채팅방을 고민·타입 태그와 연결하고 추천 근거를 표시, 방 부족 시 인기 주제 대체
  • 피부 특성을 아바타·사진에서 추정하지 않으며 선택값을 사용자 동의 없이 다른 사람에게 공개하지 않음
  • KPI: 피부 타입 선택률, 온보딩 완료율, 추천 채팅방 입장률, 첫 발화율(모두 미측정)
커뮤니티 홈 · 대화할 곳 찾기
  • 참여한 대화 복귀 아래에 내 피부 관심사 기반 추천방을 표시하고 기존 인기·최근 대화·전체 주제를 유지
  • 관심 주제·최근 대화·질문 진입을 중심으로 배치
  • 빈 화면·로딩·오류·재시도를 구분
  • 검색·브랜드에서 들어와도 관련 대화로 연결
대화 · 익명으로 묻고 답하기
  • 익명 닉네임과 간단한 작성·답변 흐름
  • 사진형 프로필은 필수로 두지 않는 안을 우선 검토
  • 글·댓글과 실시간 채팅의 역할 구분
  • 실패 시 입력을 보존하고 재방문 시 문맥 유지
상품 첨부 · 대화 중 바로 보여주기
  • 상품 검색 → 정확한 상품·옵션 선택 → 사진·이름이 있는 카드
  • 카드를 열면 해당 상품 상세와 관련 경험 확인
  • 첨부 취소·검색 결과 없음·오류·오연결 방지 확인
상품 상세 · 이해하고 선택하기
  • 상품 설명·옵션·후기·관련 대화·현재 가격·판매처
  • 직접 작성한 분류 설명과 허용된 공식·판매처 설명 구분
  • 미확인 배송비·세금·관세·재고를 확정 조건으로 표시하지 않음
  • 제휴 고지와 실제 판매처 이동 확인
브랜드·저장 · 다시 찾기
  • 로고·이름·브랜드 필터와 실제 상품 목록 연결
  • 모바일 간격·터치 영역·선택·로딩·오류 확인

화면별 UX 리스크 · 개선 백로그

P0 · 첫 방문

피부 선택 전에 이탈

가치를 모르는 상태에서 2단계 입력을 강제하면 피로가 생길 수 있다.

변경 추천 예시 먼저 노출 · 1화면 선택 · 건너뛰기 · ‘모름’ 제공
확인 KPI · 첫 화면→대화 열람 전환, 스킵 이후 첫 참여
P0 · 추천 신뢰

방은 추천되지만 들어갈 이유가 없음

추천 이유·최근 대화·읽을 만한 질문이 없으면 빈방처럼 보인다.

변경 고민 일치 이유 + 실제 활성 신호 + 질문 미리보기
확인 KPI · 추천 노출→방 입장, 방 입장→첫 유의미 행동
P0 · 언어

한영 혼용이 신뢰를 약화

버튼·채팅방 제목·에러·빈 상태 문구가 서로 다른 언어로 남지 않게 한다.

변경 ko/en 공통 키, 전체 화면·오류·알림까지 양언어 점검
확인 KPI · 언어별 첫 참여율, 미번역 문자열 건수
P1 · 채팅방

첫 발화가 어려움

익명 커뮤니티에서도 시작할 말이 없으면 읽고 떠나기 쉽다.

변경 해당 고민 질문 목록과 ‘나도 궁금해요’/질문 작성 진입 제공
확인 KPI · 방 입장→첫 질문·댓글·채팅 비율
P1 · 상품 연결
